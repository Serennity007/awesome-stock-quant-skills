## Qiita

**タイトル**：株式・クオンツ向け AI スキルの Awesome リストを作った — オープンソースの取引スキル16件を収録 + オリジナル2件（実走出力あり）

株式分析・クオンツトレード・銘柄スクリーニングの「エージェントスキル」（Claude Code / Agent Skills 形式）を集めたキュレーションリポジトリを公開しました：
https://github.com/Serennity007/awesome-stock-quant-skills

内容：

- GitHub 上のオープンソース取引スキル 16 件をライセンス遵守で収録（MIT/Apache-2.0/BSD/CC0 のみ。各ディレクトリに元の LICENSE と SOURCE.md の出典情報を保持。GPL・ライセンスなしのプロジェクトはインデックスのみで転載なし）
- 各スキルの構造化レビュー：標準的な SKILL.md の有無、依存関係、必要な API キー、今回実際に動作確認できたか（有料キーや QMT/IBKR など外部環境が必要なものは「外部環境が必要、未実測」と正直に記載）
- 筆者作成のオリジナルスキル 2 件。ドキュメントには（捏造ではない）実走の出力を掲載：
  - **buffett-value-investing**：バフェット基準で A 株を採点——5年連続 ROE>15%、安定した粗利率、低負債、営業 CF 黒字、過去 PE/PB パーセンタイル低位。記録されたデモ実行では貴州茅台が 100/100、招商銀行は 47（金融業の高レバレッジで正しく減点）
  - **technical-pattern-recognition**：移動平均線の並び、MACD ゴールデン/デッドクロス、出来高を伴う N 日高値ブレイク、出来高減少の押し目を検出しシグナル表を出力
- オリジナルスキルはいずれも無料の akshare データで動作。有料 API キー不要
- GitHub Action が毎日 UTC 01:00 に 20 銘柄の代表 A 株でバフェットスクリーニングを再実行し、レポートを `reports/` にコミット
- ドキュメントは中国語・英語・日本語の三言語

学習・研究目的のみ。投資助言ではありません。フィードバックや Issue を歓迎します。
