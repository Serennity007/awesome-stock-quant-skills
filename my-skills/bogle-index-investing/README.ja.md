# 🎯 ジョン・ボーグル・インデックス投資法｜A株指数バリュエーション温度計 + 積立バックテスト

**[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)**

作者：Serennity007 | ライセンス：MIT | データ：akshare（楽咕楽股/新浪/テンセント公開API）

> **「干し草の山から針を探すのではなく、干し草の山ごと買いなさい。」**

本スキルは、インデックスファンドの父ジョン・ボーグルのフレームワークをA株市場に機械化したものです：広基指数のPE/PB直近10年パーセンタイル・バリュエーション温度計、ボーグル式期待リターン3分解（配当利回り+利益成長+バリュエーション回帰）、積立ペース目安、月積立vs一括投資のバックテスト。沪深300 / 中証500 / 上証50 / 中証1000 に対応。

## 目次

- `SKILL.md` — スキル定義、温度計ルール、使用方法
- `scripts/index_thermometer.py` — 指数バリュエーション温度計 + 積立バックテスト
- `references/bogle_principles.md` — ボーグルの投資思想：コスト、分散、規律、ボーグル公式、平均回帰
- `bogle_test_result.csv` — 全指数テスト出力（積立バックテスト付き）

## クイックスタート

```bash
pip install akshare pandas

# 全指数の温度計
python scripts/index_thermometer.py --out bogle_thermometer.csv

# 単一指数 + 直近5年月積立バックテスト
python scripts/index_thermometer.py --index 沪深300 --dca --years 5 --out result.csv

# ボーグル公式の仮定パラメータ調整（配当利回り/利益成長率）
python scripts/index_thermometer.py --div 3.0 --growth 6.0
```

## 積立ペース目安

| PE 10年パーセンタイル | ペース |
|---|---|
| < 20% | 低温：積立額を2倍に |
| 20–40% | やや低温：通常より積極的に |
| 40–60% | 中立：通常どおり |
| 60–80% | 高め：新規積立を半減 |
| ≥ 80% | 高温：新規購入を一時停止（保有は継続） |
