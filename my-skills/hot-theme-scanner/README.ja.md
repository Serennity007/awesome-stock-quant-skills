# 🔥 A株ホットテーマスキャナー｜今日の最強テーマを秒速で把握

**[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)**

作者：Serennity007 | License：MIT | データ：akshare（東方財富/同花順公開API）

寄り付き前にこのヒート表をチェック。ストレージ、光モジュール、PCB、MLCC、商業航天、可控核聚变、固态电池、創新薬、軍工重组など現在の10大ホットテーマ辞書を内蔵し、テーマ騰落率、主力資金フロー、上昇先導株を自動スキャンして「テーマ × 騰落率 × 主力純流入 × 先導株」の構造化ヒート表を出力。A株の資金がどこに流れているか、一目で把握できます。

## クイックスタート

```bash
pip install akshare pandas

# デフォルト：5日ウィンドウ、上位20件、CSV出力
python scripts/hot_themes.py --days 5 --top 20 --out hot_themes.csv

# 当日の即時ランキングのみ
python scripts/hot_themes.py --days 1 --top 15
```

## パラメータ

- `--days`: 統計ウィンドウ、1/3/5/10 をサポート（デフォルト 5）、近い利用可能なウィンドウにフォールバック
- `--top`: 人気と見なすランキング閾値（デフォルト 20）
- `--out`: CSV 出力パス（デフォルト `hot_themes.csv`）
- `--no-proxy`: システムプロキシを無効化（スクリプトは既定でプロキシを迂回済み；旧呼び出しとの互換用）

> プロキシ注記：起動時に `HTTP_PROXY` / `HTTPS_PROXY` 環境変数をクリアし、ローカルプロキシ（例：`127.0.0.1:7890`）が東方財富・同花順APIを遮断するのを防ぎます。東方財富を優先し、失敗時は同花順に自動降格します。

## 出力フィールド

| フィールド | 説明 |
|---|---|
| `题材` | 内蔵ホットテーマ名 |
| `匹配板块` | akshareで実際にマッチしたコンセプト板名 |
| `阶段涨幅%` | 選択ウィンドウのテーマ騰落率 |
| `主力净流入（亿元）` | 選択ウィンドウの主力純流入 |
| `领涨股` | 該当ウィンドウの上昇先導株 |
| `领涨股涨幅%` | 上昇先導株の騰落率 |
| `连续上榜天数` | 1/3/5/10日ランキングで上位N位に連続掲載された推定日数 |
