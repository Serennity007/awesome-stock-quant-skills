# 🌧️ オールウェザー資産配分：A株版ダリオ式参照モデル

> 経済には成長↑/↓ × インフレ↑/↓ の 4 つの天気しかない。本スクリプトは A 株の代表的な資産で 4 つのマクロ環境を代理し、リスクパリティ風の参照ウェイトとバックテスト概要を自動出力する。

## クイックスタート

```bash
pip install akshare==1.18.96 pandas

# デフォルト：4 資産のオールウェザープール
python scripts/allocation.py --lookback 252 --out allocation.csv

# 小サンプルテスト（数銘柄のみ）
python scripts/allocation.py --codes 600519,000858,600036 --lookback 60 --out test_alloc.csv
```

## デフォルト資産プール

| 資産クラス | 代理銘柄 | 説明 |
|---|---|---|
| 株式 | 上海深300 `000300`、中证500 `000905` | A 株幅基指数 |
| 債券 | 国債ETF `511010` | 成長減速・インフレ低下局面で強い |
| 金 | 金ETF `518880` | インフレヘッジ・安全資産 |
| 商品 | 中证商品期货指数 | インフレ局面で強い |

## 出力例

ターミナルには以下が表示される：

- 各資産の直近 1 年の年率リターン、ボラティリティ、シャープレシオ
- 資産間の相関行列
- リスクパリティ風ウェイト（個別ウェイト + 株式/債券/金/商品の集計ウェイト）
- ポートフォリオのバックテスト概要：年率リターン、最大ドローダウン、シャープレシオ

結果は `allocation.csv`（または `--out` 指定パス）に `utf-8-sig` エンコーディングで書き出され、Excel でそのまま開ける。

---

## 核心ロジック

1. 各資産の日次終値を取得し、取引日を揃える。
2. 日次リターンと年率ボラティリティを計算。
3. **逆ボラティリティ**でウェイト配分：ボラティリティが低い資産ほど高ウェイト。
4. 同じ資産クラス内のウェイトを足し合わせ、株式/債券/金/商品のクラスウェイトを算出。
5. 加重ポートフォリオを構成し、年率リターン、最大ドローダウン、シャープレシオを計算。
