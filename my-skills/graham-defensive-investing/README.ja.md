# 🛡️ A株グラハム防御型7つの基準スクリーナー｜元本を守る7つの門

**[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)**

作者：Serennity007 | License：MIT | データ：akshare（東方財富／Sina Finance 公開API）

ベンジャミン・グラハムの防御型銘柄選定フレームワークをA株市場に応用。規模、流動比率、継続的収益、継続的配当、収益成長、PER < 15、PBR < 1.5 または PER×PBR < 22.5 という7つの定量基準で銘柄を機械的にスクリーニング。データが10年分ない場合は5年ウィンドウに自動降格し、どの銘柄がグラハム流「まず元本を守る」基準を満たしているかを一目で確認できる。

## クイックスタート

```bash
pip install akshare pandas

# CSI300構成銘柄をスクリーニング
python scripts/screen.py --pool hs300 --top 20 --out graham_result.csv

# 小サンプルテスト
python scripts/screen.py --codes 600519,000858,600036 --out graham_result.csv
```

## パラメータ

- `--pool`: 銘柄プール。現在は `hs300` をサポート
- `--codes`: カンマ区切りのカスタム銘柄コード。`--pool` より優先
- `--top`: 画面表示する上位件数（デフォルト 20）
- `--out`: CSV出力パス（デフォルト `graham_result.csv`）
- `--min-cap`: 最小時価総額、単位は億元（デフォルト 200）
- `--sleep`: 銘柄間の待機秒数（デフォルト 0.5、流量制限対策）

## 7つの防御基準

| 基準 | 条件 |
|---|---|
| 規模の十分さ | 時価総額 ≥ 200億元（調整可） |
| 流動比率 | 最新年度の流動比率 > 2 |
| 収益の継続性 | ウィンドウ期間中、毎年の営業外損益控除後EPS > 0 |
| 配当の継続性 | ウィンドウ期間中、毎年現金配当あり |
| 収益成長 | 期末EPS / 期首EPS > 4/3 |
| 低PER | PER（静的）< 15 |
| 低PBR | PBR < 1.5 または PER × PBR < 22.5 |

> 10年分のデータがない場合は5年ウィンドウに自動降格してラベル付け。5年未満は `NA` と表記。
