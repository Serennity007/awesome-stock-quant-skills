> **リスクを先に、キャッシュはオプション、安いだけが始まりで、触媒こそ公正価値への切符だ。**

このスキルは、セス・クラーマン（Seth Klarman）の『安全マージン（Margin of Safety）』に基づくリスク回避型ディープバリュー投資フレームワークをA株市場に応用します。ホットテーマの追跡も、チャート予測もせず、保守的な本質価値を大幅に下回り、かつ価値回帰の道筋がある候補を探します。

## ファイル一覧

- `SKILL.md` — スキル定義、4次元スコアリングロジック、使い方
- `scripts/deep_value.py` — A株ディープバリュースクリーナー（CSV + ターミナル表）
- `references/klarman_principles.md` — 『安全マージン』の核心思想：絶対収益、リスク優先、触媒重視、キャッシュはオプション、逆行投資

## クイックスタート

```bash
pip install akshare pandas

# デフォルト：沪深300成分銘柄を対象に、上位20銘柄を出力
python scripts/deep_value.py --pool hs300 --top 20 --out result.csv

# カスタムの小さな銘柄プールで検証（推奨）
python scripts/deep_value.py --codes 600519,000858,600036 --out result.csv
```

## パラメータ

- `--pool`: 銘柄プール。現在は `hs300`（沪深300）をサポート。
- `--codes`: カンマ区切りのカスタム銘柄コード。`--pool` より優先される。
- `--top`: ターミナル表示する上位件数（デフォルト 20）。
- `--out`: CSV出力パス（デフォルト `klarman_screen_result.csv`）。

## 4次元ディープバリューレーダー

| 次元 | 指標 | 説明 |
|---|---|---|
| PB絶対値と歴史パーセンタイル | 現在PB、5年PBパーセンタイル | PB<1または歴史的低位で最高得点 |
| PE低パーセンタイル | 5年PE(TTM)パーセンタイル | 低いほど高得点 |
| 時価総額/純キャッシュ比 | 時価総額 ÷（現金 - 有利子負債）| <1は時価総額が純キャッシュを下回る極厚の安全マージン |
| 52週高値からの下落 | 現在値対52週高値の下落率 | クラーマンは「下落から生まれた機会」を好む |
| リスク除外 | ST / 直近決算赤字 | 強制的に0点 |

> 銀行・不動産など高レバレッジ業界では「純キャッシュ」概念が成立しないため、スクリプトは欠損としますが、PB/PE/下落はスコアリングします。

## 出力フィールド

- `code / name`: 銘柄コードと名称
- `total`: 総合安全マージンスコア（満点100）
- `pb_score / pb / pb_percentile`: PBスコア / 現在PB / 5年パーセンタイル
- `pe_score / pe / pe_percentile`: PEスコア / 現在PE / 5年パーセンタイル
- `netcash_score / market_cap / net_cash / market_cap_to_net_cash`: 純キャッシュ次元
- `drawdown_score / current_price / high_52w / drawdown_pct`: 下落次元
- `is_st / is_loss`: リスクフラグ
- `val_source / price_source`: データソースとフォールバック説明
