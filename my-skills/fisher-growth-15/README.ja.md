# 🌱 フィリップ・フィッシャー成長株 15のポイント｜「スカトルバット」調査のための6次元スコアリング

**[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)**

作者：Serennity007 | ライセンス：MIT | データ：akshare（東方財富・新浪公開API）

> **「株式市場は、すべての物の価格を知りながら、何の価値も知らない人々で満たされている。」**

このスキルは、フィッシャーの著書『Common Stocks and Uncommon Profits』（邦題『普通株と普通でない利益』）で定量化可能なチェック項目をA株市場に応用します：成長ランウェイ（売上CAGR）、研究開発投入、利益率トレンド、資本利益率、キャッシュの質、財務の健全性。スクリプトは数千銘柄を数十銘柄まで絞り込むだけ——15のポイントの決定的な定性的部分（スカトルバット調査）は人間の仕事のままです。

## ファイル一覧

- `SKILL.md` — スキル定義、6次元スコアリングロジック、使い方
- `scripts/screen.py` — A株成長株スクリーナー（CSV + ターミナル表）
- `references/fisher_15_points.md` — 15のポイント全リスト：成長可能性、経営と文化、スカトルバット、売買規律
- `fisher_test_result.csv` — 小規模テスト出力（2026-09-26、邁瑞/海康/茅台）

## クイックスタート

```bash
pip install akshare pandas

# デフォルト：沪深300成分銘柄を対象に、上位20銘柄を出力
python scripts/screen.py --pool hs300 --top 20 --out result.csv

# カスタムの小さな銘柄プールで検証
python scripts/screen.py --codes 600519,300760,002415 --out result.csv
```

## パラメータ

- `--pool`: 銘柄プール。現在は `hs300`（沪深300）に対応。
- `--codes`: カンマ区切りの銘柄コード。`--pool` より優先。
- `--top`: ターミナルに表示する上位N銘柄（デフォルト20）。
- `--out`: CSV出力パス（デフォルト `fisher_result.csv`）。
- `--sleep`: 銘柄ごとの呼び出し間隔秒数（デフォルト0.3、レート制限対策）。

## 6次元成長質レーダー

| 次元 | 指標 | 説明 |
|---|---|---|
| 成長ランウェイ | 直近5年の売上CAGR + 利益プラス成長年数 | 売上成長は成長株の第一特徴（満点25） |
| 研究開発投入 | 研究開発費/売上高 | 経営陣が明日への投資をしているかの代理（満点20） |
| 利益率トレンド | 粗利率の水準 + 最新値トレンド | 利益率の維持または改善（満点15） |
| 資本利益率 | 直近5年の平均ROE | 株主リターンの検証（満点15） |
| キャッシュの質 | 営業キャッシュフロー/純利益 | 利益は本物か？（満点15） |
| 財務の健全性 | 最新の負債比率 | ポイント14の代理（満点10） |

判定ライン：**≥75 フィッシャー式成長株候補**；**55–74 長所も短所もあり**；**<55 フレームワーク外**。金融などR&Dデータのない業種は当該次元で中性点5。

## 出力フィールド

- `code` / `name` / `industry`：銘柄コード / 略称 / 業種
- `total`：総合スコア（満点100）
- `growth_score` / `rd_score` / `margin_score` / `roe_score` / `cash_score` / `debt_score`：各次元スコア
- `rev_cagr` / `profit_pos_years`：売上CAGR / 利益プラス成長年数
- `rd_ratio_avg` / `rd_annual`：研究開発比率の平均・年度別系列
- `gross_mean` / `gross_annual` / `roe_mean` / `ocf_to_profit_mean` / `debt_latest`：その他の財務指標
- `data_years` / `source` / `note`：有効年度数 / データソース / フォールバック注記

## 実測参考（2026-09-26、3銘柄サンプル）

邁瑞医療 78点（R&D比率 9.84%、粗利率 63.6%、ROE 29.7%）、海康威視 76点（R&D比率 11.71%）が上位、貴州茅台 63点（R&D比率 0.09% で減点）——フィッシャーのフレームワークは成熟消費株よりR&D重視の成長企業を自然と好み、直感と一致します。
