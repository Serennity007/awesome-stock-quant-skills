# 威廉·欧奈尔 · CANSLIM 投资思想整理

作者：Serennity007。本文件为对威廉·J·欧奈尔（William J. O'Neil，《投资者商报》创始人）公开著作《笑傲股市》（How to Make Money in Stocks）、《欧奈尔制胜法则》中投资思想的个人化学习整理。思想归属欧奈尔与 O'Neil Global Advisors，仅供学习研究，不构成投资建议。

---

## 一、核心理念：大牛股有共同特征

> **"百年股市里，每一轮牛市的大牛股在启动前，几乎都出现过同样的特征。"**

欧奈尔研究了 1880 年代以来所有大牛股（从通用汽车到微软、苹果），把它们的共同点提炼成 CANSLIM 七字诀。这是一套**基本面选股 + 技术面择时**的融合体系：C/A/I 决定"买什么"，N/S/L/M 决定"何时买"。

## 二、CANSLIM 七要素详解（脚本量化 + 人工定性）

| 字母 | 欧奈尔原意 | 脚本对应 |
|---|---|---|
| C（Current quarterly earnings） | 当季 EPS 同比 ≥ +25%，增长必须加速 | `quarter_yoy`（净利润同比，20 分） |
| A（Annual earnings increases） | 近 3 年年度增长 ≥ 25%，ROE ≥ 17% | `annual_growth_3y`（15 分） |
| N（New products, New highs） | 新产品/新管理层/股价新高——**创 52 周新高时买入，而不是跌到"便宜"时** | `dist_from_250d_high`（15 分） |
| S（Supply and demand） | 流通盘小、需求放大（放量上涨） | `vol_ratio_5_60`（10 分） |
| L（Leader or laggard） | 只买领导者：RS 相对强度 ≥ 87（前 13%） | `excess_ret_120d` + `rps_percentile`（20 分） |
| I（Institutional sponsorship） | 机构持仓增加——需要"聪明的钱"背书 | `inst_hold_ratio`（10 分） |
| M（Market direction） | 顺势而为：大盘在上升通道才做多 | `M_score`（沪深300 vs 50日线，10 分） |

### 无法量化的两件事

1. **带柄杯形态（Cup with Handle）**：欧奈尔最推崇的底部结构——股价先跌后横盘成"杯"，再小幅回落成"柄"，突破柄部即买点。脚本只检查"接近新高"，形态识别需人工完成。
2. **突破买点（Pivot point）**：不是新高就买，而是突破带柄杯的精确买点且当日放量 ≥ 50%。追高与突破是两回事。

## 三、买卖纪律（比选股更重要）

| 铁律 | 内容 |
|---|---|
| 7% 止损 | 从买点下跌 7-8% 无条件卖出，绝无例外 |
| 20-25% 止盈 | 大部分仓位赚 20-25% 就走；极强领涨股可持有 3-6 个月以上 |
| 3J 换股 | Jogs：行情走弱、突破失败、上涨乏力时先出 |
| 不摊薄 | 亏损的股票绝不加仓——" amateur 平均成本，professional 止损" |
| 分批建仓 | 首次买 1/2，突破后确认再加 |

> "你所有的股票都应该在 7% 规则的保护之下。这是我认为最重要的单一规则。"

## 四、欧奈尔与价值投资的根本分歧

| 议题 | 欧奈尔（动量） | 巴菲特（价值） |
|---|---|---|
| 买入时机 | 创新高突破时 | 便宜时（恐惧中） |
| 持有期 | 数周至数月 | 数年至数十年 |
| 止损 | 7% 铁律 | 基本面不变就不卖 |
| 估值 | PE 不重要（"最牛的股票启动时 PE 往往很高"） | PE 是核心 |
| 分散 | 集中 4-6 只 | 能力圈内适度集中 |

两种体系在逻辑上自洽但**操作上互斥**：一份 CANSLIM 高分名单与一份巴菲特高分名单几乎不重叠是正常现象。使用者必须想清楚自己在做哪一种，不能混着用。

## 五、给使用者的提醒

1. **M 优先于一切**：欧奈尔统计，多数股票跟随大盘方向。M 失败时最好的操作是不操作。
2. **RPS ≥ 87 的本意**：欧奈尔的 RS 是 12 个月口径、与全市场比较；本脚本用 120 日超额收益近似，池内 RPS 百分位仅在 `--pool hs300` 全池模式下有意义。
3. **A 股语境差异**：A 股涨停板/融券限制让突破形态的短线行为与美股不同，7% 止损在 A 股高波动下会被频繁触发——可以放宽到 10%，但绝不能没有止损。
4. **换手成本**：CANSLIM 是高换手体系，交易佣金与印花税长期侵蚀收益，回测或实操都应计入。
