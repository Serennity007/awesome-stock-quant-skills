# 🚀 ウィリアム・オニール CANSLIM｜7要素チェックリスト・スクリーナー（A株）

**[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)**

作者：Serennity007 | ライセンス：MIT | データ：akshare（新浪/東方财富公開API）

> **「歴史上のすべての大型急騰株には、急騰前に共通して識別可能な特徴があった。」**

本スキルは、ウィリアム・オニール（『株で勝つ』著者）のCANSLIM体系をA株市場に機械化したものです：C（四半期利益YoY≥25%）、A（年間成長）、N（250日高値への接近）、S（出来高急増）、L（沪深300に対する相対強度）、I（機関保有）、M（市場トレンド）——アルファベットごとの合否表とスコア（満点100）、プールモードではRPSパーセンタイルも出力。バリュー系スキルと相補関係にあります。

## 目次

- `SKILL.md` — スキル定義、7要素スコアリングロジック、使用方法
- `scripts/screen.py` — A株CANSLIMスクリーナー（CSV + 端末テーブル）
- `references/oneil_canslim_rules.md` — オニールの投資思想：7要素詳細、カップ・ウィズ・ハンドル、売買規律と7%損切り
- `canslim_test_result.csv` — 小サンプルのテスト出力

## クイックスタート

```bash
pip install akshare pandas

# デフォルトプール：沪深300、上位20件表示
python scripts/screen.py --pool hs300 --top 20 --out result.csv

# カスタム小サンプルテスト
python scripts/screen.py --codes 600519,300760,002415 --out result.csv
```

## 7要素スコアカード

| 文字 | 基準 | 配点 |
|---|---|---|
| C | 直近四半期純利益YoY ≥25% で満点 | 20 |
| A | 直近3年の年平均利益成長率 ≥25% で満点 | 15 |
| N | 終値が250日最高値の15%以内で満点 | 15 |
| S | 直近5日/60日の出来高比率 ≥1.5 で満点 | 10 |
| L | 120日リターンの沪深300超過分 ≥30pp で満点 | 20 |
| I | 機関保有比率 ≥10% で満点；データなしは中立5点 | 10 |
| M | 沪深300が50日移動平均上（全プール共通） | 10 |

判定ライン：**≥70 かつ C/A/N/L 成立 → CANSLIM候補**；**50–69 ウォッチリスト**；**<55 フレームワーク外**。
