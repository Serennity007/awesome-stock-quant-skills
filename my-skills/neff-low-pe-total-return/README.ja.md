# 🏦 ジョン・ネフ低PER投資法｜総リターン比率≥2で「嫌われ者の堅実企業」を発見

**[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)**

作者：Serennity007 | ライセンス：MIT | データ：akshare（東方財富・巨潮・騰訊公開API）

> **「好まれない業界における、しっかりした位置づけの企業。」**

このスキルは、ジョン・ネフ（ウィンザー・ファンド31年間で市場を年平均3.1ポイント上回る）の低PER体系をA株市場に応用します：全市場中央値に対する個別PERの割引率、(成長率+配当利回り)/PER≥2という総リターン比率のゴールデンスタンダード、継続配当、ファンダメンタルの下限。スクリプトがCSVを出力し、「安いのは嫌われているからか、壊れているからか」を人間が吟味します。

## ファイル一覧

- `SKILL.md` — スキル定義、7次元スコアリングロジック、使い方
- `scripts/screen.py` — A株低PERスクリーナー（CSV + ターミナル表）
- `references/neff_principles.md` — ネフの核心思想：低PER哲学、総リターン公式、逆張り設計、売却規律
- `neff_test_result.csv` — 小規模テスト出力（2026-09-26、招商銀行/茅台/五糧液）

## クイックスタート

```bash
pip install akshare pandas

# デフォルト：沪深300成分銘柄を対象に、上位20銘柄を出力
python scripts/screen.py --pool hs300 --top 20 --out result.csv

# カスタムの小さな銘柄プールで検証
python scripts/screen.py --codes 600519,000858,600036 --out result.csv
```

## パラメータ

- `--pool`: 銘柄プール。現在は `hs300`（沪深300）に対応。
- `--codes`: カンマ区切りの銘柄コード。`--pool` より優先。
- `--top`: ターミナルに表示する上位N銘柄（デフォルト20）。
- `--out`: CSV出力パス（デフォルト `neff_result.csv`）。
- `--sleep`: 銘柄ごとの呼び出し間隔秒数（デフォルト0.3、レート制限対策）。

## 7次元低PERレーダー

| 次元 | 指標 | 説明 |
|---|---|---|
| 低PER | 個別PER(TTM) / 全市場PER中央値 | ウィンザーのPERは長期にわたり市場の4〜6割（満点25） |
| 総リターン比率 | (利益成長率平均 + 配当利回り) / PER | ネフのゴールデンスタンダード ≥2（満点25） |
| 配当利回り | 直近5回の配当を実スパンで年間化 / 現在価格 | 市場が見方を変えるのを待つ間の給料（満点15） |
| 成長下限 | 成長率平均 >0 かつプラス成長年数≥3 | 「嫌われ」と「壊れ」の区別（満点10） |
| 資本利益率 | 直近5年の平均ROE | ビジネスの質（満点10） |
| 低負債 | 最新の負債比率 | 財務健全性（満点10） |
| キャッシュの質 | 営業キャッシュフロー/純利益 | 利益は本物か（満点5） |

判定ライン：**≥75 ネフ式候補**；**55–74 ウォッチリスト**；**<55 フレームワーク外**。市場中央値の取得に失敗した場合は絶対PER段階にフォールバック。

## 出力フィールド

- `code` / `name` / `industry`：銘柄コード / 略称 / 業種
- `total`：総合スコア（満点100）
- `low_pe_score` / `trr_score` / `dividend_score` / `growth_score` / `roe_score` / `debt_score` / `cash_score`：各次元スコア
- `pe_ttm` / `pe_market_ratio` / `pe_percentile`：PER(TTM) / 市場中央値比 / 歴史分位
- `total_return_ratio` / `dividend_yield` / `dividend_events` / `dividend_span_years`：総リターン比率 / 年間配当利回り / 配当回数 / 測定スパン
- `profit_growth_mean` / `roe_mean` / `debt_latest` / `ocf_mean`：その他の財務指標
- `data_years` / `val_source` / `fin_source` / `note`：有効年度数 / データソース / フォールバック注記

## 実測参考（2026-09-26、3銘柄サンプル）

招商銀行 88点（PER 6.76、市場中央値の0.18倍；配当利回り 6.34%；総リターン比率 2.33 でゴールデンライン通過）、貴州茅台 76点、五糧液 65点——銀行など低PER・高配当の嫌われセクターはネフのフレームワークに自然と合致します。
