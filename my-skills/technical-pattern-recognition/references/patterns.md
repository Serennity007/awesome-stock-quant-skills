# 技术形态说明（patterns.md）

本文件说明 `scripts/patterns.py` 识别的各类形态的定义、默认参数与解读要点。

## 数据与指标约定

- 数据：akshare `stock_zh_a_daily`（新浪日线，前复权），默认取近 250 个交易日。
- 均线：MA5 / MA10 / MA20 / MA60（收盘价简单移动平均）。
- MACD：EMA12 − EMA26 = DIF，DIF 的 9 日 EMA = DEA。
- 量比：当日成交量 / 20 日平均成交量。

## 形态定义

### MA_BULLISH — 均线多头排列
MA5 > MA10 > MA20 > MA60。短中长期趋势一致向上，是趋势跟踪的基本前提。多头排列本身不指示买点，只说明"处于上升趋势"。

### MA_BEARISH — 均线空头排列
MA5 < MA10 < MA20 < MA60。下降趋势。空头排列下的任何"抄底"信号都应谨慎对待。

### MACD_GOLDEN — MACD 金叉
近 3 个交易日内 DIF 上穿 DEA。零轴上方的金叉（多头市场内的回调结束）历史上比零轴下方的金叉更可靠；本脚本不区分零轴位置，解读时请结合 `dif` 值的正负。

### MACD_DEATH — MACD 死叉
近 3 个交易日内 DIF 下穿 DEA。与金叉对称，常作为减仓/回避提示。

### VOL_BREAKOUT — 放量突破 N 日新高
当日收盘价超过此前 N 日（默认 60，可用 `--window` 调整）的最高收盘价，且当日成交量 ≥ 20 日均量的 1.5 倍。放量是突破有效性的关键确认；无量突破（量比 < 1.5）不触发本信号。注意假突破风险：突破后 1–3 日若跌回前高之下，信号失效。

### PULLBACK_MA — 缩量回踩均线
前提为多头排列（MA_BULLISH），且当日收盘价在 MA20 的 ±2% 区间内，成交量 ≤ 20 日均量的 0.8 倍。逻辑：上升趋势中的回调若伴随缩量，说明抛压衰竭，是趋势延续型买点候选。若回踩伴随放量（量比 > 1.5）或跌破 MA20 超过 2%，则不触发——那可能是趋势破坏而非健康回调。

### NO_SIGNAL / INSUFFICIENT_DATA
未命中任何形态 / 数据长度不足（少于 max(65, window+2) 根K线）。

## 使用注意

1. 所有形态都是**滞后指标**，由历史价格计算而来，不预测未来。
2. 信号组合比单一信号更有意义：`MA_BULLISH + PULLBACK_MA`（趋势中缩量回调）与 `VOL_BREAKOUT`（启动确认）是两类常见的高关注度组合。
3. 必须结合基本面与市场环境二次判断；本工具输出仅供学习研究，不构成投资建议。
