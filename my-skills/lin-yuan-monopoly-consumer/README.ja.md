# 🍶 林園式独占+依存性消費投資法｜「口元の必需品モート」だけに投資

**[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)**

作者：Serennity007 | ライセンス：MIT | データ：akshare（東方財富・巨潮・騰訊公開API）

> **「私は口元関連、依存性があり、独占的で、粗利率だけが嘘をつかない会社にだけ投資する。」**

このスキルは、林園氏の公開インタビュー・講演で繰り返し語られた投資フレームワークをA株市場に応用します。ホットテーマの追跡もチャート予測もせず、4つの財務指標を継続的に適用します——**口元関連の必需品、粗利率50%超、持続的な高ROE、高配当率**——「独占+依存性」を持つ候補を抽出し、その後定性的分析（モート、バリュエーション、能力の輪）で最終判断を行います。

## ファイル一覧

- `SKILL.md` — スキル定義、4大鉄則のスコアリングロジックと使い方
- `scripts/screen.py` — A株林園式初筛スクリプト（CSV + ターミナル表）
- `references/lin_yuan_rules.md` — 林園投資思想の整理：独占、口元関連、粗利率、買ったら売らない、規律

## クイックスタート

```bash
pip install akshare pandas

# デフォルト：沪深300成分銘柄を対象に、上位20銘柄を出力
python scripts/screen.py --pool hs300 --top 20 --out result.csv

# カスタムの小さな銘柄プールで検証
python scripts/screen.py --codes 600519,000858,600036 --out result.csv
```

## パラメータ

- `--pool`: 銘柄プール。現在は `hs300`（沪深300）をサポート。
- `--codes`: カンマ区切りのカスタム銘柄コード。`--pool` より優先される。
- `--top`: ターミナル表示する上位件数（デフォルト 20）。
- `--out`: CSV出力パス（デフォルト `lin_yuan_screen_result.csv`）。
- `--min-gross`: 粗利率のハード閾値（デフォルト 50%）。
- `--min-roe`: ROEのハード閾値（デフォルト 15%）。
- `--min-div`: 直近12カ月配当利回りのハード閾値（デフォルト 1.0%）。
- `--sleep`: 銘柄ごとのリクエスト間隔（デフォルト 0.3秒、レート制限対策）。

## 4大選別鉄則

| 次元 | 代理指標 | 重み |
|---|---|---|
| 独占・価格決定力 | 5年間の粗利率平均50%超、かつ変動が小さい | 30 |
| 持続的な高ROE | 5年間でROE≥15%の年数と平均ROE | 25 |
| 株主還元 | 直近12カ月配当利回り + 5年間の配当継続性 | 20 |
| 依存性/必需品業界 | 白酒/漢方薬/調味料/乳製品/ビール等のホワイトリスト一致 | 15 |
| 財務健全性 | 最新自己資本比率 | 10 |

## 出力フィールド

- `code` / `name`：銘柄コード / 略称
- `score`：総合スコア（満点100）
- `linyuan_pass`：ハード閾値をパスしたか
- `sw_industry` / `sw_sector`：申万業種分類
- `gross_mean` / `gross_annual`：粗利率平均 / 5年系列
- `roe_mean` / `roe_annual`：ROE平均 / 5年系列
- `dividend_yield` / `payout_recent`：配当利回り / 直近1年の配当額
- `debt_latest`：最新負債比率
- `addictive_tag`：依存性/必需品業界タグ
- `data_years` / `source` / `note`：有効年度数、データソース、フォールバック説明
