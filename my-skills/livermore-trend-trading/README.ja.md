# 🎯 リバモア流A株トレンド投機｜5つの纪律で突破点と損切りを守る

**[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)**

作者：Serennity007 | License：MIT | データ：akshare（東方財富/新浪公開API）

「大きな儲けは、動き回ることではなく、待つことで生まれる。」本スキルはジェシー・リバモアのトレンド投機の紀律を機械化します：**N日高値の軸となるポイントブレイクアウト、出来高確認、縮量押し目による2次エントリー**を識別し、**一日反転 / 出来高伴う行き詰まり**の危険シグナルを警告。さらに**ピラミッド建玉の試行フレームワーク**を出力し、「試行建玉→確認後追加→損切り」を数字で示します。

## クイックスタート

```bash
pip install akshare pandas

# デフォルト：サンプル銘柄3件、直近250営業日、突破ウインドウ60日
python scripts/pivotal_points.py --codes 600519,000858,600036 --out signals.csv

# ウインドウを短くして直近の突破を確認
python scripts/pivotal_points.py --codes 600519,000858 --days 120 --window 30 --out signals.csv
```

## パラメータ

- `--codes`：カンマ区切りの6桁A株コード（必須）
- `--days`：取得する直近営業日数（デフォルト250）
- `--window`：N日高値突破ウインドウ（デフォルト60）
- `--out`：CSV出力パス（デフォルト `livermore_signals.csv`）
- `--no-proxy`：システムプロキシを無効化（スクリプトは既にデフォルトで無効化済み、互換性用パラメータ）

> プロキシ説明：起動時に `HTTP_PROXY` / `HTTPS_PROXY` などの環境変数をクリアし、ローカルプロキシ（例：`127.0.0.1:7890`）が東方財富/新浪APIをブロックするのを防ぎます。まず東方財富の日足APIを試し、失敗したら新浪日足に自動降格します。

## 出力フィールド

| フィールド | 説明 |
|---|---|
| `code` | 6桁の銘柄コード |
| `name` | 銘柄名 |
| `date` | シグナル日 |
| `close` | 最新終値 |
| `close_chg_pct` | 当日騰落率（%） |
| `volume_ratio` | 当日出来高 / 20日平均出来高 |
| `ma20` | 20日移動平均 |
| `ma60` | 60日移動平均 |
| `window_high` | 突破ウインドウ内の最高終値 |
| `dist_to_high_pct` | 現在値からウインドウ高値までの乖離（%） |
| `signals` | 発生したシグナル（カンマ区切り） |
| `position_plan` | シグナルに基づくピラミッド建玉提案 |

## シグナル一覧

| シグナル | 意味 |
|---|---|
| `KEY_BREAKOUT` | 出来高を伴うN日高値突破 |
| `WEAK_BREAKOUT` | 出来高不足の高値突破、偽突破に注意 |
| `PULLBACK_ENTRY` | 上昇トレンド中の縮量押し目、2次エントリー候補 |
| `ONE_DAY_REVERSAL` | 一日反転：高値更新後に安値近くで引ける |
| `VOLUME_STAGNATION` | 出来高拡大に対して値幅が小さく上ヒゲあり |
| `NO_SIGNAL` | 明確なシグナルなし |
