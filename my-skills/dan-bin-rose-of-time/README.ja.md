> **「時間は最も価値ある資産であり、偉大な企業と共に成長すべきである。」**

本スキルは、但斌（東方港湾創業者、『時間の薔薇』著者）の偉大な企業投資フレームワークをA株市場に機械化したものです：長い坂（売上CAGRの成長ランウェイ）、深い雪（高い粗利率＝価格決定力）、複利エンジン（5年連続ROE）、時間の薔薇（持続的な配当）、キャッシュの質、財務健全性、成長の一貫性の7次元スコアリング。スクリプトは候補を絞り込むだけで、「次の世代に引き継げるビジネスか」の定性判断は人間の仕事です。

## 目次

- `SKILL.md` — スキル定義、7次元スコアリングロジック、使用方法
- `scripts/screen.py` — A株偉大な企業スクリーナー（CSV + 端末テーブル）
- `references/danbin_rose_principles.md` — 但斌の投資思想：時間の薔薇、偉大な企業の基準、2つのルート、売買規律
- `danbin_test_result.csv` — 小サンプルのテスト出力

## クイックスタート

```bash
pip install akshare pandas

# デフォルトプール：沪深300、上位20件表示
python scripts/screen.py --pool hs300 --top 20 --out result.csv

# カスタム小サンプルテスト
python scripts/screen.py --codes 600519,000858,600036 --out result.csv
```

## パラメータ

- `--pool`：銘柄プール。現在 `hs300`（沪深300）をサポート。
- `--codes`：カンマ区切りの銘柄コード。`--pool` より優先。
- `--top`：端末に表示する上位N件（デフォルト20）。
- `--out`：CSV出力パス（デフォルト `danbin_result.csv`）。
- `--sleep`：銘柄ごとの呼び出し間隔秒数（デフォルト0.3、レート制限対策）。

## 7次元スコアリングレーダー

| 次元 | 指標 | 説明 |
|---|---|---|
| 長い坂 | 5年売上CAGR | 成長ランウェイ（満点15） |
| 深い雪 | 平均粗利率 | ブランドの価格決定力（満点20） |
| 複利エンジン | 5年平均ROE | 複利のエンジン（満点20） |
| 時間の薔薇 | 年換算配当利回り | 複利の分かち合い（満点15） |
| キャッシュの質 | 営業キャッシュフロー/純利益 | 利潤は本物か（満点10） |
| 財務健全性 | 最新負債比率 | 低レバレッジ（満点10） |
| 成長の質 | 純利益プラス成長年数 | 一貫性（満点10） |

判定ライン：**≥75 偉大な企業候補**；**55–74 ウォッチリスト**；**<55 フレームワーク外**。
