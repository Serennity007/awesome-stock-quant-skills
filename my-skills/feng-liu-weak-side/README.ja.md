作者：Serennity007 | License：MIT | データ：akshare（東方財富/同花順/新浪公開API）

> **市場で最も弱い情報受信者であると仮定し、オッズ優先で逆張りし、集中するが、間違いを素早く認める。**

本スキルは、高毅資産の馮柳氏による「弱者体系」の逆張り投資フレームワークをA株市場に適用したものです。ホットテーマを追わず、情報戦をせず、「大きく下落したがまだ死んでいない」銘柄を体系的に探します。中核スクリプト `scripts/screen.py` は「下落幅、バリュエーション、ファンダメンタルズ、関心度」の4次元でスコアリングし、各銘柄に「オッズ / 確率」のラベルを付与します。

## ファイル一覧

- `SKILL.md` — スキル定義、4次元スコアリングロジックと使い方
- `scripts/screen.py` — A株「弱者体系」初選スクリプト（CSV + ターミナル表）
- `references/feng_liu_framework.md` — 弱者体系の核心思想：弱者仮説、オッズ優先、逆張い、集中保有、素早い認錯、バリュートラップの見分け方

## クイックスタート

```bash
pip install akshare pandas

# デフォルトは沪深300成分株、上位20件を出力
python scripts/screen.py --pool hs300 --top 20 --out weak_side_result.csv

# 小さなカスタム銘柄群で検証
python scripts/screen.py --codes 600519,000858,600036 --out weak_side_result.csv
```

## パラメータ

- `--pool`: 銘柄群、現在は `hs300`（沪深300）をサポート
- `--codes`: カンマ区切りのカスタム銘柄コード、`--pool` より優先
- `--top`: ターミナル表示件数（デフォルト 20）
- `--out`: CSV出力パス（デフォルト `weak_side_result.csv`）

## 逆張り4次元レーダー

| 次元 | 指標 | 説明 |
|---|---|---|
| オッズ（下落幅） | 52週高値からの下落率 | 40%超の下落を高オッズ起点とする |
| オッズ（バリュエーション） | PE/PBの近3年パーセンタイル | 20%未満を歴史的低位とみなす |
| 確率（ファンダメンタルズ） | 黒字維持、売上・利益未崩壊、ROE/負債適正 | 構造的悪化のバリュートラップを除外 |
| 低関心度 | 換手率（%） | 低いほど市場から忘れられているか嫌われている |

## 出力フィールド

- `code` / `name` / `industry`: コード / 銘柄名 / 業種
- `close` / `high_52w` / `drawdown_pct`: 現在値 / 52週高値 / 下落率
- `pe_ttm` / `pb` / `pe_percentile_3y` / `pb_percentile_3y`: バリュエーションと近3年パーセンタイル
- `turnover_pct`: 最新換手率（%）
- `latest_revenue` / `latest_profit` / `revenue_yoy` / `profit_yoy`: 直近期売上・利益（億元）と前年比増減率
- `weak_score` / `odds_label` / `probability_label`: 総合スコア / オッズラベル / 確率ラベル
- `framework_note`: オッズ・確率の出所説明
- `weak_pass`: 硬い閾値を通過したか
