# 冯柳“弱者体系”/逆向投资 · 学习整理

作者：Serennity007。本文件为高毅资产冯柳先生公开访谈、演讲、持仓交流及市场记录的个人化学习整理，仅供学习研究，不构成投资建议。

冯柳的投资思想以公开信息为准，本文件可能存在理解偏差。任何投资决策都应建立在独立研究与自身能力圈判断之上。

---

## 1. 核心假设：把自己当成市场上最弱的信息接收者

> “我不是强者，所以我只做弱者能做的事。”——冯柳

- **承认信息劣势**：不追逐消息、不比拼研究速度、不靠内幕或高频信息。
- **相信价格已经反映多数已知信息**：如果股价大幅下跌，说明悲观预期已被市场交易得比较充分。
- **弱者的时间优势**：没有业绩排名压力，可以等待；用时间来换空间，等市场自我纠错。

## 2. 赔率优先，而非概率优先

传统价值投资强调“高概率”——买确定性强的伟大公司。冯柳体系更强调“高赔率”：

- **赔率优先的定义**：向下空间有限（跌了很多、估值很低），向上空间较大（只要不被彻底证伪，就有修复机会）。
- **不追求精确预测**：只要判断“不会更糟”或“大概率不会死”，就有机会。
- **接受看错**：高赔率的机会允许一定比例看错，整体期望值为正即可。

### 赔率评估的四个维度

| 维度 | 问题 | 代理指标 |
|---|---|---|
| 跌幅 | 股价是否已经历大幅调整？ | 距 52 周高点回撤幅度 |
| 估值 | 估值是否处于历史低位？ | PE/PB 近 3-5 年百分位 |
| 基本面 | 公司是否还活着、还能赚钱？ | 净利润为正、营收未大幅下滑 |
| 关注度 | 市场是否已遗忘或厌恶它？ | 换手率、研报覆盖、论坛热度 |

## 3. 逆向买入：在“没人要”的时候买

- **左侧买入**：不等待趋势确认，越跌越买（但需要控制节奏和仓位）。
- **买预期最差、但实质未崩的标的**：行业或公司遭遇阶段性利空，但核心竞争力未被摧毁。
- **回避“万众瞩目”的抄底**：当所有人都在喊“便宜”时，往往还不够便宜。

### 逆向买入的常见场景

1. **行业周期底部**：需求短期受挫，但长期需求仍在。
2. **政策冲击后的错杀**：监管、反垄断、集采等政策导致估值压缩，但企业盈利能力未根本恶化。
3. **业绩一次性暴雷**：非核心资产减值、一次性费用等导致利润下滑，但主业现金流稳定。
4. **流动性或风格杀**：市场追逐热点，传统蓝筹被持续卖出，估值跌至历史极端低位。

## 4. 集中持仓，但认错要快

- **敢下重注**：真正符合“高赔率+可纠错”标准的机会不多，遇到后要敢于集中。
- **仓位的本质是置信度**：赔率越高、可验证条件越清晰，仓位可以越重。
- **严格止损/认错**：如果核心假设被证伪（基本面真崩了、逻辑被颠覆），要迅速离场，不摊薄、不幻想。
- **“看错”是体系的一部分**：冯柳并不追求每笔都赢，而是通过赔率让整体账户期望值为正。

## 5. 弱者体系的买入后：等待市场纠错

- **不主动催化**：弱者没有能力改变市场共识，只能等待。
- **用基本面验证替代猜测股价**：关注企业经营数据是否如预期改善，而非每日 K 线。
- **时间不是朋友，也不是敌人**：只有在基本面未进一步恶化时，时间才站在逆向投资者一边。

## 6. 与“价值陷阱”的区别

弱者体系最容易踩的坑是把“便宜但持续恶化”当成“高赔率”。区分要点：

| 弱者体系标的 | 价值陷阱 |
|---|---|
| 基本面阶段性受损，但核心竞争力仍在 | 商业模式被颠覆或永久受损 |
| 盈利为正，现金流能撑过低谷 | 持续亏损，依赖融资续命 |
| 行业周期或情绪导致的估值压缩 | 行业需求长期萎缩 |
| 有清晰可验证的拐点信号 | 看不到好转催化剂 |

## 7. 实践检查清单

- [ ] 股价跌幅是否足够大（最好 > 40%）？
- [ ] 估值是否处于自身历史低位（PE/PB 百分位 < 20%）？
- [ ] 公司是否仍在赚钱（净利润为正）？
- [ ] 营收/利润下滑是否属于一次性或周期性，而非结构性崩溃？
- [ ] 负债率是否可控，不至于在低谷期破产？
- [ ] 市场关注度是否显著下降（换手率低迷、负面讨论占主导）？
- [ ] 是否有可跟踪的拐点指标（订单、库存、价格、政策）？
- [ ] 如果核心假设错误，退出价格/条件是否明确？
