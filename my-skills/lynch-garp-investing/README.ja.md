# 🚀 ピーター・リンチ GARP / テンバガー A株選別器｜リンチ流にスーパーで銘柄を選ぶ

**[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)**

作者：Serennity007 | License：MIT | データ：akshare（東方財富/同花順/騰訊公開API）

ピーター・リンチは株式選びをスーパーでの買い物に例えました：身近な商品・サービス・ブランドから始め、"妥当な価格での成長"（GARP）を見つける。本スキルはその視点をA株に機械的に落とし込み、PEG、連続利益成長、負債比率、ROE安定性を自動計算し、リンチの6分類（缓慢增长/稳定增长/快速增长/周期/困境反转/隐蔽资产）でタグ付けして、AIによる深掘り分析にそのまま使える構造化テーブルを出力します。

## クイックスタート

```bash
pip install akshare pandas

# デフォルト：沪深300成分株、上位20件
python scripts/screen.py --pool hs300 --top 20 --out garp_result.csv

# カスタム小株（高速検証用）
python scripts/screen.py --codes 600519,000858,600036 --out garp_result.csv
```

## 選別基準

| 次元 | 優秀 | 許容 | 説明 |
|---|---|---|---|
| PEG | < 1.0 | < 1.5 | PE(TTM) / 利益成長率；最新成長率が負の場合は5年平均を用いた参考PEGを表示 |
| 連続利益成長 | ≥ 3年 | ≥ 2年 | 直近N年の純利益前年比が連続でプラス |
| 負債比率 | < 40% | < 60% | デフォルト `--max-debt 60`；銀行など高レバレッジ業種は別途判断 |
| ROE | > 15% | > 10% | 5年間で比較的安定 |
| リンチタグ | 快速增长/稳定增长 | 隐蔽资产/困境反转 | 周期股・缓慢增长は慎重に |

## 出力フィールド

| フィールド | 説明 |
|---|---|
| `code` / `name` | 銘柄コード / 略称 |
| `score` | GARP 総合スコア（満点100） |
| `lynch_tag` | リンチ6分類タグ |
| `garp_pass` | PEG<1、連続利益成長≥2年、負債比率<閾値を満たすか |
| `peg` / `peg_note` | 計算PEGと注記 |
| `pe_ttm` / `pb` | 現在のPE(TTM)、株価純資産倍率 |
| `avg_profit_growth` | 直近5年の純利益成長率平均 |
| `consecutive_profit_years` | 連続利益成長年数 |
| `debt_ratio` / `roe_latest` | 負債比率 / 最新ROE |
| `industry` | 業種 |
