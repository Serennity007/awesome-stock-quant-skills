# 曲线结构计算方法

本方法只处理同一品种、同一 CSV 内的一组到期合约价格。它描述“这份数据呈现的到期结构”，不检验数据来源，也不推导交易动作。

## 时间与单位约定

- 所有天数按**自然日**计算，固定使用 365 天作为年化分母；不引入交易日历、节假日、结算日或 252 交易日年化。
- 到期日只使用 `expiry` 字段，不区分最后交易日、交割日或结算日；三者可能不同，CSV 不提供。
- 计算不涉及合约乘数、货币、价格单位或 tick size，因此输出的百分比只在同一品种、同一单位内可解释。
- 所有价格取 CSV 的 `last` 原值；脚本不检查它来自结算价、收盘价还是最后一笔成交。
- 已到期（`expiry <= as_of_date`）的合约不进入计算；这一规则等价于“截止日后仍在挂牌的合约才构成当前曲线”，但它不是可执行的换月规则。

## 公式

记按到期日升序排列的未到期合约为 `c_1 ... c_n`（`n >= 2`），第 `i` 份合约的到期天数为 `d_i`。

```text
d_i = (expiry_i - as_of_date).days
spread_i = last_{i+1} - last_i
spread_pct_i = spread_i / last_i * 100
days_between_i = d_{i+1} - d_i
annualized_slope_pct_i = spread_i / last_i * 365 / days_between_i * 100
total_annualized_change_pct = (last_n - last_1) / last_1 * 365 / (d_n - d_1) * 100
```

`near` 是相邻对中到期更近的合约，`far` 是更远的一份。`days_between` 按自然日且至少为 1：未到期保证 `d_i >= 1`，到期日唯一且有序保证相邻间隔为正。

给出 `--spot` 时，以最近月合约为基准：

```text
basis = spot - last_1
basis_pct_of_futures = basis / last_1 * 100
annualized_basis_pct = basis / last_1 * 365 / d_1 * 100
```

基差为负表示现货低于近月期货（期货升水），为正表示现货高于近月期货（期货贴水）。年化基差只是同一差值换算到 365 自然日的线性比率，不是持有现货或展期的可实现收益。

## 形态分类

分类只比较相邻价差的符号：

| 条件 | classification |
|---|---|
| 所有 `spread_i > 0` | `contango`（远月升水） |
| 所有 `spread_i < 0` | `backwardation`（远月贴水） |
| 所有 `spread_i == 0` | `flat` |
| 其余（符号混合） | `mixed` |

- 分类不参考价格绝对水平、成交量、持仓量或价差幅度；后两者只输出，不参与判断。
- `mixed` 是有效描述：近月升水、远月贴水的组合常见于库存、季节性与期限溢价叠加，不代表数据错误。
- `total_annualized_change_pct` 只用首末两份合约，是两点斜率；它不描述中间路径，也不代表按该路径移仓可获得的收益。
- 相邻合约之间可能存在流动性、保证金、交割规则差异；分类不区分这些差异。

## 读数限制

- **价格口径**：结算价、收盘价与最后成交价的经济含义不同，混用时价差与年化都失去可比性。脚本无法识别口径。
- **日历近似**：固定 365 自然日会忽略长假、交割月规则与真实交易日分布；临近到期或跨长假的年化容易失真。
- **展期收益**：roll yield 是“持有并移仓”的假设收益，需要连续合约、可成交价格、乘数与换月成本。本脚本只给单点价差年化，不计算展期收益，更不是已实现收益。
- **基差**：现货与期货的标的、品质、交货地、单位与时间戳都必须可比；仅给出一个数字不会让基差自动有意义。
- **形态解释**：contango/backwardation 可以由利率、仓储成本、便利收益、库存与预期共同造成，不能单凭形态推断涨跌方向。
- **数据缺口**：CSV 没有交易所、币种、单位、乘数、成交量口径与数据供应商字段；缺失信息不会被脚本补齐。

这些限制写进 JSON 的 `scope` 与 `limitations`，并要求在结论中一并保留。
