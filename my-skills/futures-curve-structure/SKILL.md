# 我的期货曲线结构研究方法

这套方法只回答“给定一份本地合约价格表，这个品种当前的到期结构长什么样”。它把形态描述、年化换算和基差拆开，允许结论是数据不足或形态混合；不把 contango/backwardation 直接翻译成买卖动作。

## 目标与边界

- 研究对象是同一品种、同一报价口径的多个到期合约；不同品种、不同交易所或不同单位的曲线不能直接比较绝对值。
- 输出只有描述性事实：到期天数、相邻价差、年化斜率、形态分类与可选基差。它们不是价格预测、胜率或收益证明。
- 脚本不拉取行情、不构造连续主力合约、不判断流动性、不建模交割与保证金；输入由研究者提供，并对其口径负责。
- 数据不足（未到期合约少于两个、未到期到期日重复、价格非法）时直接报错，不补齐、不插值、不猜合约。

## 输入与判断顺序

1. **固定品种与时间**：写明品种代码、交易所、价格单位、报价口径（结算价/收盘价/成交价）与数据截止时间。`--product` 只是自由文本标签，脚本不会验证它对应真实品种。
2. **检查字段**：CSV 必填 `contract,expiry,last`，可选 `volume,open_interest`。到期日必须是 `YYYY-MM-DD`；`last` 必须是有限正数；空的数量字段记为 `null`，不记为 0。
3. **先过滤已到期合约**：到期日不晚于截止日的行仍逐字段校验，但不进入曲线，数量记入 `excluded_expired`。已到期价格不应参与当前形态判断。
4. **按到期排序再算相邻对**：按自然日排序，不按合约代码字符串或成交量排序。相邻对指到期日相邻的两份合约，不是“主力/次主力”换月规则。
5. **先看价差方向，再看年化**：分类只看相邻价差符号：全正为 contango，全负为 backwardation，全零为 flat，其余为 mixed。年化是把价差换成固定 365 自然日的线性斜率，不是可成交收益；公式见[曲线计算方法](references/curve-method.md)。
6. **基差单独算**：只有明确给出 `--spot` 才输出基差与年化基差；现货与期货的标的、单位、时间必须可比，否则基差没有意义。
7. **把限制写进结论**：交割规则、流动性、节假日与合约乘数都可能影响读数；脚本没有验证这些项，交付时必须保留缺口说明。

## 可复现的本地脚本

有合约价格 CSV 时，用 `scripts/futures_curve.py` 机械复算上述事实。脚本只读本地文件，不联网、不预测价格、不生成交易指令。

```bash
python scripts/futures_curve.py --csv references/example-curve.csv --product CU_DEMO --as-of 2026-10-15 --spot 70950 --out output/curve.json
```

从本 Skill 目录运行。数值保留完整浮点、不做四舍五入；输出以新文件创建，已有文件不会被覆盖，输入与输出路径相同会被拒绝。示例为合成数据，仓库中的 `references/example-output.json` 是同组输入的一次实跑副本；字段约定见[输入与输出契约](references/data-contract.md)，逐项手工核对见[合成曲线走查](references/example-analysis.md)。

## 输出与限制

- JSON 包含 `curve`、`adjacent_spreads`、`structure`、可选 `basis`、`scope`、`limitations`、输入哈希与生成时间；`curve` 按到期升序。
- 年化分母固定为 365 自然日，且只对单一价差做线性换算；跨长假、临近交割或缺少交易日历时，年化会被放大或缩小。
- 分类只说明相邻价差符号，不说明幅度、流动性或可交易性；`mixed` 不是无效数据，而是该切片的真实描述。
- `last` 可能是结算价、收盘价或最后一笔成交价，CSV 与脚本都不声明、不校验；`volume`/`open_interest` 的单位与口径同样未验证。
- 脚本不计算合约乘数、货币换算、保证金、滑点或换月成本，也不输出展期收益或已实现收益。

## 风险与表达边界

- 不把 contango/backwardation 直接表述为“必涨/必跌”；曲线形态是研究输入，不是交易信号。
- 不把年化斜率当成可实现收益；展期收益假设需要连续移仓、可成交价格与成本模型，本脚本没有这些。
- 不因单一品种曲线就推断宏观供需；利率、仓储、便利收益、库存与季节性都可能造成同一形态。
- 不把合成示例或局部截图当作行情记录；示例文件只用于验证计算行为。
- 具体合约的到期日、最后交易日、交割规则与保证金以交易所公告为准；静态文档不充当当前规则。
