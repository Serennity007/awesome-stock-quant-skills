# concept-stock-mapper 使用笔记：题材炒作的结构与风险

## 1. 题材轮动的基本规律

A 股题材炒作通常遵循以下节奏：

1. **发酵期**：消息/政策/事件驱动，少数人关注，龙头率先涨停，板块涨幅排名开始上升。
2. **加速期**：媒体与资金合力推动，板块内多只个股连板，成交量与资金净流入快速放大。
3. **高潮期**：全网讨论，后排跟风股批量补涨，板块成交额达到阶段性峰值。
4. **分化/退潮期**：龙头打开涨停或跌停，资金净流出，后排股率先大跌，题材进入淘汰赛。

**轮动特征**：

- 资金容量有限，多数题材持续 3–7 个交易日，少数大题材（如 AI、新能源）可反复活跃数月。
- 新老题材存在跷跷板效应：新题材启动时，老题材往往抽血回落。
- 同一大主题下细分题材会轮动，例如新能源车里 `"固态电池"` → `"锂电池"` → `"充电桩"` 的阶段性切换。

## 2. 领涨 / 中军 / 跟风三种结构

一个题材启动后，成分股通常会分化出三种角色：

### 2.1 领涨股（龙头）

- **特征**：涨幅最大、封板最早、连板数最多、市场辨识度最高。
- **识别**：按 `--sort change_pct` 排序，前排涨停或涨幅 > 7% 的个股。
- **作用**：龙头的强弱决定题材情绪。龙头持续连板，题材才能继续；龙头跌停，题材大概率退潮。
- **风险**：连续加速后一旦开板，回撤剧烈；普通投资者很难买到，买到的往往是阶段性顶部。

### 2.2 中军（容量核心）

- **特征**：市值相对较大、成交额高、换手适中（通常 3%–15%）、走势较龙头更稳。
- **识别**：按 `--sort main_force` 或 `--sort turnover` 排序，成交额大且涨幅未必最大的个股。
- **作用**：中军承载大资金进出，是题材能否走成趋势的关键。中军不倒，题材更容易反复。
- **风险**：中军弹性小于龙头，若题材退潮，中军也会跟随补跌，只是幅度可能较小。

### 2.3 跟风股（后排）

- **特征**：涨幅小、启动晚、逻辑边缘、换手低或异常高（投机性强）。
- **识别**：同一题材内涨幅靠后、 name 与题材关联度弱、成交额小的个股。
- **作用**：题材高潮期补涨，退潮期最先被杀。
- **风险**：追高跟风股亏损概率最高，应尽量避免。

## 3. 用本工具辅助判断题材的要点

1. **先看板块强度**：
   - 板块涨幅排名是否进入前 10%？
   - 资金净流入是否为正且显著？
   - 上涨家数 / 总家数是否 > 50%？

2. **再看内部结构**：
   - 前排是否有 3 只以上涨停或大涨？
   - 中军是否有成交额大、走势稳健的个股？
   - 后排跟风是否过多？跟风过多说明题材可能进入高潮。

3. **多题材对比**：
   - 同时传入 2–3 个相关关键词，比较板块涨幅、资金净流入、前排个股强度。
   - 资金净流入大、前排涨停多的题材通常更值得关注。

## 4. 追高风险提示

- **不要追已经全面高潮的题材**：当全网都在讨论、后排股批量补涨时，往往已是短期顶部。
- **不要追一字板龙头**：能买到时大概率是顶部或巨震开始。
- **设置止损**：题材股的波动远大于白马股，单笔亏损控制在可接受范围内。
- **区分消息驱动与业绩驱动**：纯消息炒作持续性差，有业绩兑现预期的题材更可能走成趋势。
- **注意大盘环境**：题材炒作在震荡市/弱市更活跃，但在大盘系统性下跌时也容易全线溃散。
