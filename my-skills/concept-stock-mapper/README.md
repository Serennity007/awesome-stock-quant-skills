# 🎯 题材关键词→概念股映射器｜输入热点，秒拉成分股+强度PK

**[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)**

作者：Serennity007 | License：MIT | 数据：akshare（东方财富/同花顺公开接口）

给一个热点题材关键词，立刻生成概念股清单；给多个关键词，直接对比谁更强。自动模糊匹配同花顺/东方财富概念板块，拉出成分股并按涨幅、换手率、主力资金排序，是盘中看到新闻后“这个题材有哪些票、哪个细分更强”的快速入口。

## 典型场景

- 盘中/复盘看到 `"可控核聚变"`、`"商业航天"`、`"固态电池"` 等新闻，想立刻知道相关股票有哪些。
- 比较 `"商业航天"` 与 `"低空经济"` 当前谁更强：看板块涨幅、资金净流入、前排个股涨幅。
- 找出题材内部结构：领涨股（涨停或涨幅最大）、中军（成交额大、换手适中）、跟风股（涨幅小、换手低）。

## 安装依赖

```bash
pip install akshare pandas
```

已验证环境：Python 3.11 + akshare 1.18.96 + pandas。

## 命令行用法

```bash
# 单题材，默认按涨跌幅取前 15
python scripts/concept_mapper.py --keywords 商业航天

# 多题材对比，按主力资金净流入排序
python scripts/concept_mapper.py --keywords 商业航天,核聚变,固态电池 --top 15 --sort main_force --out result.csv

# 按换手率排序
python scripts/concept_mapper.py --keywords 固态电池 --top 20 --sort turnover
```

## 参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--keywords` | 必填 | 逗号分隔的题材关键词，如 `商业航天,核聚变` |
| `--top` | 15 | 每个题材输出的成分股数量 |
| `--sort` | `change_pct` | 排序维度：`change_pct`（涨跌幅）、`turnover`（换手率）、`main_force`（主力资金净流入） |
| `--out` | `concept_stocks.csv` | 输出 CSV 路径 |
| `--no-proxy` | — | 兼容旧参数，现脚本已默认禁用系统代理，传与不传效果相同 |

## 数据源与降级策略

1. **概念板块匹配**：优先使用 `akshare.stock_board_concept_name_ths()` 同花顺概念列表做模糊匹配。
2. **题材强度**：使用 `akshare.stock_board_concept_info_ths()` 获取板块涨幅、资金净流入、成交额等。
3. **成分股明细**：
   - 优先尝试 `akshare.stock_board_concept_cons_em()`（东方财富成分股，含主力资金）。
   - 若该接口因网络或数据源问题失败，自动降级到同花顺概念详情页抓取成分股（含代码、名称、现价、涨跌幅、换手率、成交额）。
4. **主力资金**：
   - 东方财富成分股接口可用时，直接取其中的主力净流入字段。
   - 同花顺个股资金流页面抓取失败时会自动重试一次；若仍失败，则以 **成交额** 作为资金活跃度的代理指标，并在 CSV 的 `note` 列标注。
5. **代理处理**：脚本默认自动禁用系统代理（清除 `HTTP_PROXY`/`HTTPS_PROXY` 等环境变量），避免本地代理（如 `127.0.0.1:7890`）导致同花顺/东财接口失败。旧参数 `--no-proxy` 仍保留兼容，但已非必需。

## 输出示例

终端会打印题材强度对比表与每个题材的前 N 名成分股；CSV 中会追加 `theme_rank`（该股在对应题材内的排序）与 `note`（降级备注）列。

## 风险提示

- 题材炒作轮动快，今日热点明日可能退潮；输出仅为某一时刻的快照。
- `领涨股` 往往一字涨停或大幅高开，追高风险极高。
- 成分股可能因概念蹭热度而被纳入，需结合基本面与题材纯正度人工甄别。
