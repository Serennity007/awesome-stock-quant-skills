# 🎯 テーマキーワード→概念股マッパー｜キーワード入力で構成銘柄と強度比較を即取得

**[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)**

作者：Serennity007 | License：MIT | データ：akshare（東方財富/同花順公開API）

ホットテーマのキーワードを渡せば、概念股リストを即座に生成。複数キーワードを渡せば、どのテーマが強いかその場で比較。東方財富/同花順の概念板をあいまい一致でマッチングし、構成銘柄を騰落率、回転率、主力資金で並べ替える。ニュースを見た後の「このテーマはどの銘柄？ どの細分が強い？」への最速入口です。

## 典型的なシーン

- 盤中/解読時に「可控核聚变」「商业航天」「固态电池」などのニュースを見て、関連銘柄をすぐ知りたい。
- 「商业航天」と「低空经济」、現在どちらが強いか比較：セクター騰落率、資金純流入、上位銘柄の騰落率を確認。
- テーマ内部構造を把握：上昇先導株（ストップ高や大幅高）、中核株（成交額大、回転率適中）、追随株（小幅上昇、回転率低）。

## 依存ライブラリ

```bash
pip install akshare pandas
```

検証済み環境：Python 3.11 + akshare 1.18.96 + pandas。

## コマンドライン使い方

```bash
# 単一テーマ、デフォルトは騰落率上位15件
python scripts/concept_mapper.py --keywords 商业航天

# 複数テーマ比較、主力資金純流入で並べ替え
python scripts/concept_mapper.py --keywords 商业航天,核聚变,固态电池 --top 15 --sort main_force --out result.csv

# 回転率で並べ替え
python scripts/concept_mapper.py --keywords 固态电池 --top 20 --sort turnover
```

## パラメータ

| パラメータ | デフォルト | 説明 |
|---|---|---|
| `--keywords` | 必須 | カンマ区切りのテーマキーワード。例：`商业航天,核聚变` |
| `--top` | 15 | テーマごとに出力する構成銘柄数 |
| `--sort` | `change_pct` | 並べ替え軸：`change_pct`（騰落率）、`turnover`（回転率）、`main_force`（主力資金純流入） |
| `--out` | `concept_stocks.csv` | 出力CSVパス |
| `--no-proxy` | — | 後方互換用。現在はスクリプトがデフォルトでシステムプロキシを無効化済み |

## データソースとフォールバック戦略

1. **概念板マッチング**：`akshare.stock_board_concept_name_ths()` の同花順概念板リストを使ってあいまい一致。
2. **テーマ強度**：`akshare.stock_board_concept_info_ths()` でセクター騰落率、資金純流入、成交額などを取得。
3. **構成銘柄詳細**：
   - まず `akshare.stock_board_concept_cons_em()`（東方財富構成銘柄、主力資金含む）を試行。
   - ネットワークまたはデータソースの問題で失敗した場合、同花順概念詳細ページから構成銘柄を取得するフォールバック（コード、名称、終値、騰落率、回転率、成交額）。
4. **主力資金**：
   - 東方財富構成銘柄インターフェースが使える場合、その主力純流入フィールドを直接使用。
   - 同花順個別株資金フローページの取得に失敗した場合、1回再試行します。それでも失敗した場合、**成交額**を資金活発度の代理指標とし、CSV の `note` 列に注記。
5. **プロキシ処理**：スクリプトはデフォルトでシステムプロキシを無効化（`HTTP_PROXY`/`HTTPS_PROXY` などの環境変数をクリア）し、`127.0.0.1:7890` などのローカルプロキシによる東方財富/同花順接続失敗を回避します。旧パラメータ `--no-proxy` は互換性のため残していますが、必須ではありません。

## 出力

ターミナルにはテーマ強度比較表と各テーマの上位N件構成銘柄が表示されます。CSV には `theme_rank`（テーマ内順位）と `note`（フォールバック注記）列が追加されます。

## リスク注意

- テーマ炒作は回転が速く、今日の人気テーマが明日には沈む可能性があります。出力は一時点のスナップショットです。
- `上昇先導株` はしばしばストップ高または大幅ギャップアップしており、追いかけるリスクは極めて高いです。
- 構成銘柄はテーマの乗っかりで含まれる場合もあり、ファンダメンタルズとテーマの純度を人工的に確認する必要があります。
