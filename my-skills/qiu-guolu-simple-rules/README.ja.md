# 🌙 月を数え星を数えるな｜邱国禄「三好」A株龙头スコアリング

**[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)**

作者：Serennity007 | License：MIT | データ：akshare（東方財富/同花順/騰訊/新浪公開API）

> **業界構造が個別銘柄のアルファより重要。安さが最も確かな道理。勝ってから戦え。**

本スキルは、邱国禄（きゅう こくろく）氏の著書『投資で最も単純なこと』の「好業種・好企業・好価格」という三好基準をA株に機械的に落とし込みます。沪深300またはカスタム銘柄リストから、業界内時価総額トップ3の龙头（「月」）だけをスコアリングし、二三線の「星」は追いません。

## ファイル一覧

- `SKILL.md` — スキル定義、3次元スコアリングロジック、使い方
- `scripts/screen.py` — A株「三好」龙头スクリーナー（CSV + ターミナル表）
- `references/qiu_principles.md` — 邱国禄氏の核心投資原則まとめ

## クイックスタート

```bash
pip install akshare pandas

# デフォルト：沪深300成分銘柄を対象に、上位20銘柄を出力
python scripts/screen.py --pool hs300 --top 20 --out qiu_result.csv

# カスタムの小さな銘柄プールで検証
python scripts/screen.py --codes 600519,000858,600036 --out qiu_result.csv
```

## パラメータ

- `--pool`: 銘柄プール。現在は `hs300`（沪深300）をサポート。
- `--codes`: カンマ区切りのカスタム銘柄コード。`--pool` より優先される。
- `--top`: ターミナル表示する上位件数（デフォルト 20）。
- `--out`: CSV出力パス（デフォルト `qiu_result.csv`）。
- `--sleep`: 銘柄ごとのリクエスト間隔（デフォルト 0.3秒、レート制限対策）。

## 3次元スコアリングレーダー

| 次元 | 指標 | 説明 |
|---|---|---|
| 好業種 | 業界内時価総額ランキング | トップ3が 25/20/15 点；それ以外は 0 点——「月を数え、星を数えるな」 |
| 好企業 | 5年間のROE＋営業収入成長率 | ROE平均が高く安定しているほど高得点；安定した正の成長は市場シェア/競争優位の代理指標 |
| 好価格 | PE/PBの歴史的パーセンタイル | パーセンタイルが低いほど高得点；履歴データがない場合は絶対PE/PBでフォールバック評価 |

## 出力フィールド

- `code` / `name` / `industry`：銘柄コード / 略称 / 業種
- `total_score`：総合スコア（満点100）
- `industry_rank` / `industry_score`：業界内時価総額ランク / 業種スコア
- `roe_score` / `growth_score`：ROE次元スコア / 営業収入成長率次元スコア
- `price_score` / `pe_score` / `pb_score`：価格次元総合スコア / PEパーセンタイルスコア / PBパーセンタイルスコア
- `pe_ttm` / `pb` / `pe_percentile` / `pb_percentile`：現在のバリュエーションと歴史パーセンタイル
- `roe_avg` / `roe_std` / `revenue_growth_avg`：ROE平均 / 標準偏差 / 営業収入成長率平均
- `total_mv_yi`：時価総額（億元）
- `data_years`：有効な年度数
- `val_source` / `fin_source` / `note`：データソースとフォールバック説明
