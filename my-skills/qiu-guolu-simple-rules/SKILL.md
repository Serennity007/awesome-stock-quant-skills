# 🌙 数月亮不数星星｜邱国鹭「三好」A 股龙头打分器

> **行业格局大于个股 α，便宜是硬道理，胜而后求战。**

本技能把邱国鹭《投资中最简单的事》里的核心思想机械化落地到 A 股：不追热点、不猜题材，只按“好行业、好公司、好价格”三把尺子，从沪深300或自定义股票池中找出各行业龙头（“月亮”），输出结构化 CSV 供进一步定性研究。

## 3 维打分（满分 100）

| 维度 | 核心问题 | 代理指标 | 权重 |
|---|---|---|---|
| 1. 好行业 | 行业格局是否清晰？龙头有没有溢价？ | 同行业内按市值排名，前 3 名得分 | 25 |
| 2. 好公司 | 公司是否具备持续竞争优势？ | 近 5 年 ROE 均值与稳定性；营收增速近似市占率逻辑 | 40 |
| 3. 好价格 | 当前估值是否处于历史低位？ | PE/PB 历史估值分位 | 35 |

> “数月亮不数星星”——脚本直接按行业市值排序，只给各行业前 3 名龙头行业分；非龙头默认行业分为 0，避免在二三线标的上浪费研究精力。

## 使用方法

```bash
pip install akshare pandas

# 默认用沪深300成分股作为股票池
python scripts/screen.py --pool hs300 --top 20 --out qiu_result.csv

# 或用自定义股票池（推荐先小样本验证）
python scripts/screen.py --codes 600519,000858,600036 --out qiu_result.csv
```

参数说明：

- `--pool`: 股票池，目前支持 `hs300`。
- `--codes`: 逗号分隔的自定义股票代码，优先级高于 `--pool`。
- `--top`: 终端展示前 N 名（默认 20）。
- `--out`: CSV 输出路径（默认 `qiu_result.csv`）。
- `--sleep`: 每只股票间隔秒数（默认 0.3，用于防接口限流）。

## 分析流程（配合 AI 使用）

1. **跑初筛**：运行 `screen.py` 得到候选龙头名单与三好得分。
2. **读原则**：对照 `references/qiu_principles.md`，用“胜而后求战、逆向投资、便宜是硬道理、行业格局大于个股 α”做自我检查。
3. **定性验证**：对高分龙头逐一判断——行业格局是否真正清晰、ROE 稳定性是否来自护城河、当前低估值是否反映短期情绪还是长期恶化。
4. **仓位与纪律**：只在能力圈内、安全边际充足时下注；看不懂的“星星”坚决放弃。

## 数据来源与降级策略

- 数据来自 `akshare` 公开接口（东方财富/同花顺/腾讯/新浪）。
- 脚本启动时默认禁用系统代理，避免 `127.0.0.1:7890` 等本地代理阻断数据源。
- 估值与市值优先使用 `stock_value_em` 获取历史 PE/PB 与总市值；失败时降级到 `stock_zh_a_spot_tx` 获取当前估值（此时无法计算历史分位）。
- 财务指标优先使用 `stock_financial_analysis_indicator`；若营收增速等关键字段缺失，自动用新浪利润表补充；整体失败则降级到新浪三大报表手工计算 ROE 与营收增速。
- 行业映射优先使用最新一期 `stock_yjbb_em` 业绩报表中的“所处行业”。
- 所有网络调用均带 3 次指数退避重试，调用间 `time.sleep(0.15)` 防限流。
