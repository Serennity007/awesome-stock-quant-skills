# 🌀 ソロス反身性スキャナー（A株）

> 価格は現実を映す鏡ではなく、現実そのものの一部だ。

このスキルはジョージ・ソロスの**反身性理論**を中国A株向けの定量スキャナーに落とし込んだものです。**価格モメンタム**と**ファンダメンタルの成長率**を比較し、**出来高の混雑度**を測り、**トレンド転換シグナル**を検出して、各銘柄に反身性段階のラベルを付けます。

これは「明日上がるか」という予測ツールではありません。問いかけるのは、**「市場は今、自己強化のループにあるのか、それとも自己崩壊を始めているのか」**です。

## 主な機能

| 機能 | 説明 |
|---|---|
| 価格・業績乖離スキャン | 価格上昇＋業績悪化 →「脆弱なバブル候補」；価格下落＋業績改善 →「期待差候補」 |
| 出来高混雑度 | 当日換手率 ÷ 20日平均換手率；2倍以上で混雑警報 |
| 転換シグナル | MACDゴールデン/デッドクロス、RSI買われすぎ/売られすぎ、移動平均線の順列/逆列 |
| 反身性段階ラベル | 正のフィードバック強化期、正のフィードバック脆弱期、負のフィードバック深化期、負のフィードバック過度期、均衡・観察圏 |

