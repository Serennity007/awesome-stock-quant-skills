# 张磊 · 高瓴长期结构性价值投资原则整理

作者：Serennity007。本文件为对张磊公开著作《价值》及公开访谈、演讲、股东大会/LP 沟通中投资思想的个人化学习整理。思想归属张磊及高瓴资本（Hillhouse Capital），仅供学习研究，不构成投资建议。

---

## 一、核心理念：长期结构性价值投资（Long-term Structural Value Investing）

> **“我们是创业者，只不过恰好是投资人。”**

张磊把投资定义为“用资本参与社会价值创造”。长期结构性价值不是看短期利润波动，而是看企业能否在产业变迁中创造持续、可积累的社会价值，并因此获得长期复利。

### 1.1 长期主义（Long-termism）

- **时间是最好的称重器**：短期价格由情绪决定，长期价值由企业创造的真实现金流决定。
- **把资金投给“时间的朋友”**：愿意为未来 5–10 年的竞争力持续投入，而非追求季度业绩。
- **不去赌风口，而是投结构**：看重产业趋势、商业模式、护城河深度，而非主题炒作。
- **忍受非线性**：优秀企业往往在早期投入期利润不明显，甚至短期数据难看，但长期回报曲线更陡峭。

### 1.2 动态护城河（Dynamic Moat）

张磊认为，传统静态护城河（品牌、牌照、成本优势）只是门槛，真正的护城河是**企业持续创造价值的能力**。

| 护城河类型 | 静态视角 | 动态视角 |
|---|---|---|
| 品牌 | 已有知名度 | 能否持续获得消费者心智与信任 |
| 成本 | 规模带来低价 | 能否通过技术/组织迭代持续降本 |
| 网络效应 | 用户基数大 | 生态能否自我演化、迁移成本是否提高 |
| 转化成本 | 客户切换难 | 产品/服务是否随时间越用越“重” |
| 创新能力 | 专利数量 | 研发体系、人才密度、试错与学习速度 |

> 动态护城河的核心是“创造价值 + 持续学习 + 组织进化”。

### 1.3 选人是最大的风控（People as the Ultimate Risk Control）

- **投资就是投人**：张磊反复强调，比商业模式更重要的是企业家精神、价值观与长期格局。
- **寻找“长期主义创业者”**：
  - 对行业有深刻洞察与使命感，而非只想套利。
  - 愿意把资源投向研发、组织、品牌等长期资产。
  - 在困难时期仍坚持做正确的事。
- **看管理层资本配置**：分红、回购、并购、研发投入是否服务于长期价值，而非市值管理。
- **警惕“机会主义管理层”**：频繁跨界、追逐热点、高送转、高质押、减持套现等信号。

### 1.4 重仓中国 / 科技创新

- **中国市场的结构性机会**：消费升级、产业升级、技术自主、制造业升级、医药创新。
- **科技创新是长期价值的重要来源**：
  - 高研发投入、高人才密度、高试错迭代速度的公司。
  - 把技术转化为产品力和客户价值，而非单纯堆专利。
- **“从 0 到 1”与“从 1 到 N”并重**：既看技术突破，也看技术产业化、规模化的能力。

### 1.5 哑铃策略（Barbell Strategy）

- **一边压舱石**：稳健现金流、高确定性、弱周期、行业龙头（消费、医药、基础设施等）。
- **一边高成长**：高研发、高资本开支、行业空间大、长期复利潜力强（科技、创新药、新能源、高端制造等）。
- **中间避免“平庸区”**：不投既没有成长性、也没有确定性的公司。
- **用长期资金匹配长期资产**：避免短久期负债去支撑长久期资产。

## 二、长期结构性价值的选股线索

1. **连续多年的营收/利润双增长**
   - 收入与利润同步增长，说明增长有业务实质而非一次性损益。
   - 更看重增长的“质量”与“可持续性”，而非单一年份爆发。

2. **持续的高研发或资本开支投入**
   - 研发费用率稳定或提升，说明企业在为下一个 5 年积累能力。
   - 资本开支扩张但 ROE/ROIC 不恶化，说明投入在转化为竞争力。
   - 警惕：资本开支扩张但现金流持续恶化、负债率飙升。

3. **行业空间大、增速高于行业平均**
   - 行业渗透率仍有提升空间，或企业份额仍在提升。
   - 企业增速持续高于行业平均，说明它正在获取结构性份额。

4. **ROE/ROIC 趋势向上**
   - 资本回报不仅高，而且在改善，说明护城河加深、效率提升。
   - 结合现金流看：高 ROE 必须有经营现金流支撑，否则可能是加杠杆或会计调节。

5. **管理层的长期资本配置能力**
   - 不盲目跨界并购、不频繁定增摊薄老股东。
   - 在周期低点敢于投入，在高点不盲目扩张。

## 三、可迁移到 A 股的注意点

- **区分“真长期投入”与“资本浪费”**：重资产扩张需看产能利用率、ROIC 是否回升。
- **金融/周期行业的特殊性**：银行、保险、地产的“负债率”“研发投入”口径与非金融企业差异大，需单独用行业指标。
- **A 股主题炒作频繁**：长期结构性价值常与短期股价背离，筛选结果需配合定性研究。
- **数据来源的局限**：akshare 公开接口未直接披露 ROIC，可用 ROE 代理；研发费用与资本开支需从三大报表手工计算。
