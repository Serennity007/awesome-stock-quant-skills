## 1. 思想归属人物

- **詹姆斯·西蒙斯（James Simons, 1938–2024）**：数学家、密码学家、量化投资先驱，文艺复兴科技公司创始人。
- **文艺复兴科技公司 / 大奖章基金（Renaissance Technologies / Medallion Fund）**：以纯数据驱动、高频统计套利、跨资产信号挖掘著称的量化对冲基金。大奖章基金自 1988 年以来创造了极高的费后年化收益，但其具体方法对外界仍是黑箱。

## 2. 核心投资哲学

### 2.1 数据驱动，信号重于叙事

- 投资决策应基于可重复、可验证的统计信号，而非宏观经济故事、行业景气叙事或管理层愿景。
- 市场短期价格行为中存在着大量微小的、非随机的模式（patterns）。
- 这些模式往往很微弱、很短暂，需要海量数据和快速执行才能转化为正期望收益。

### 2.2 短线均值回归与多因子复合

- 大奖章基金以**短线交易**闻名，持仓周期可能从数小时到数周。
- 其信号体系中常见两类逻辑：
  - **短期反转（mean reversion）**：价格短期超跌后倾向于回弹。
  - **短期动量（momentum）**：价格趋势在极短期内可能延续。
- 真正的优势不在于单个因子，而在于**大量弱相关信号的加权复合**与**动态权重调整**。

### 2.3 严格风控

- 单笔交易期望收益很小，因此必须依靠：
  - 高分散（同时持仓大量标的）。
  - 严格止损与仓位控制。
  - 对杠杆、相关性、尾部风险的持续监控。
- 模型失效时，宁可降低仓位、暂停交易，也不依赖“这次不一样”的叙事。

### 2.4 隐藏交易足迹

- 大资金短线交易若被市场察觉，会被反向捕食。
- 因此执行层面强调：
  - 拆单、暗池、TWAP/VWAP 等算法执行。
  - 避免在单一方向上过快堆积仓位。
  - 不断变换信号组合，降低被复制或反向工程的风险。

### 2.5 人才与基础设施

- 招募数学家、物理学家、统计学家、计算机科学家，而非传统金融背景分析师。
- 自建数据清洗、特征工程、回测、交易执行系统。
- 对交易成本、滑点、数据质量有极致追求。

## 3. 本 skill 的风格化致敬框架

本 skill 把上述思想简化为一个 A 股多因子打分器：

| 维度 | 西蒙斯风格解释 | 本 skill 代理指标 |
|---|---|---|
| 动量 | 极短周期内的趋势延续 | 20日、60日收益率 |
| 反转 | 短期超跌后的均值回归 | 5日收益率（负值越强越超卖） |
| 低波动 | 低波异象 + 控制风险 | 20日收益年化波动率 |
| 量能 | 成交量验证价格行为 | 近5日均量 / 近20日均量 |
| 均线偏离度 | 偏离均线的回摆潜力 | 收盘价与60日均线的绝对偏离 |

> 注：上述指标仅为教学演示，真实大奖章基金会使用更高频、更多样、更复杂的信号，并配合严格的回测与执行系统。

## 4. 使用原则（配合 AI 使用）

1. **把因子当作弱信号**：单只股票的高分不代表必然上涨，而是说明它在多个维度上符合本框架的统计特征。
2. **关注组合而非个股**：西蒙斯风格的优势来自大量交易的期望累积，因此更适合作为组合初筛，而非单押一只。
3. **动态验证**：市场环境变化会导致因子失效，需要定期回测各因子的 IC、IR 与衰减速度。
4. **风控优先**：任何实盘使用都必须设置止损、仓位上限、行业/风格敞口控制。
