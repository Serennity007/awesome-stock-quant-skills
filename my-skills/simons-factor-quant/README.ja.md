# 🧮 サイモンズ式ファクター定量｜A株短期統計パターンを捉える5次元シグナル

**[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)**

作者：Serennity007 | ライセンス：MIT | データ：akshare（東方財富・新浪公開API）

> **物語よりシグナル、直感よりデータ。**

このスキルは、ジェームズ・サイモンズとメダリオン・ファンドの公開されている投資哲学に触発され、A株市場のデータを5つの定量化可能な統計シグナル——モメンタム、リバーサル、低ボラティリティ、出来高トレンド、移動平均乖離——に変換します。`scripts/factor_scan.py`は銘柄群を1銘柄ずつスコアリングし、複合ファクターランキングをCSVとターミナル表で出力します。

> ⚠️ メダリオン・ファンドの本当のモデルは非公開です。本スキルは学習用フレームワークであり、投資助言ではありません。

## ファイル一覧

- `SKILL.md` — スキル定義、5次元ファクターロジック、使い方
- `scripts/factor_scan.py` — A株マルチファクタースキャナー（CSV + ターミナル表）
- `references/simons_methods.md` — ジェームズ・サイモンズ／メダリオン・ファンドの学習整理ノート

## クイックスタート

```bash
pip install akshare pandas

# デフォルト：沪深300成分銘柄を対象に、上位20銘柄を出力
python scripts/factor_scan.py --pool hs300 --top 20 --out result.csv

# カスタムの小さな銘柄プールで検証
python scripts/factor_scan.py --codes 600519,000858,600036 --top 10 --out result.csv
```

## パラメータ

- `--pool`: 銘柄プール。現在は `hs300`（沪深300）をサポート。
- `--codes`: カンマ区切りのカスタム銘柄コード。`--pool` より優先される。
- `--top`: ターミナル表示する上位件数（デフォルト 20）。
- `--out`: CSV出力パス（デフォルト `simons_factor_result.csv`）。
- `--end-date`: 終了日。`20231231` と `2023-12-31` の両方に対応（デフォルトは当日）。
- `--lookback`: 遡及カレンダー日数（デフォルト 150）。

## 5次元ファクターレーダー

| 次元 | 代理指標 | 説明 |
|---|---|---|
| モメンタム | 20日・60日収益率 | トレンド継続スコア |
| リバーサル | -5日収益率 | 短期超売られ、平均回帰候補 |
| 低ボラティリティ | -20日年間ボラティリティ | 低ボラ効果、リスク管理 |
| 出来高トレンド | 近5日平均出来高 / 近20日平均出来高 | 出来高による価格行動の確認 |
| 移動平均乖離 | -\|終値/60日移動平均 - 1\| | 乖離が小さい銘柄を好む |

## 出力フィールド

- `code / name`：銘柄コードと名称
- `total`：複合ファクタースコア（0–100）
- `momentum_score / reversal_score / volatility_score / volume_score / ma_deviation_score`：5次元スコア
- `ret_5d / ret_20d / ret_60d / vol_20d_annual / volume_ratio_5_20 / ma60_deviation`：生のファクター値
- `close / latest_date`：最新終値と日付
- `data_days / source`：有効データ件数とデータソース
