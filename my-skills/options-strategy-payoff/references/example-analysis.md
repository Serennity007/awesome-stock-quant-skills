# 合成情景走查

本例读取 [example-legs.csv](example-legs.csv) 与由它实际运行生成的 [example-output.json](example-output.json)。期货 100、行权价 110、权利金 3、数量 1、乘数 1 全部是人为构造的合成 fixture，不是任何交易所的行情、成交价或真实持仓，也不构成对某一行情的判断。其余几组手算同样使用合成数字，可由 `analyze()` 直接复现，本文不逐一保存独立 JSON。

## 示例数据与生成命令

```csv
leg_id,instrument,side,strike,quantity,premium,multiplier
futures_long_100,futures,buy,,1,100,1
call_short_110,call,sell,110,1,3,1
```

在 Skill 目录按 [SKILL.md](../SKILL.md) 的示例命令运行（策略标签 `covered-call-demo`，价格 80/90/97/100/110/120），结果写到 `output/payoff.json`；仓库中的 `example-output.json` 是这次运行的副本。`source_sha256` 对应 CSV 原始字节，`generated_at_utc` 每次运行不同。

## 备兑看涨：逐项手算

腿定义：期货 buy 1 手入场 100（乘数 1）；卖出 call，行权价 110，权利金 3，数量 1，乘数 1。

- 净权利金：只有 call 腿进入求和，`(+1)×1×100` 不参与，`(-1)×1×3 = -3`，即净收取 3（credit）。
- `0 < S ≤ 110`：期货 `S − 100`；卖出 call 到期作废，收取的 3 保留。合计 `S − 100 + 3 = S − 97`。
- `S ≥ 110`：期货 `S − 100`；卖出 call 赔付 `S − 110`，再加上保留的权利金 3：`S − 100 − (S − 110) + 3 = 13`。
- 盈亏平衡：解 `S − 97 = 0`，得 `S = 97`；与 `example-output.json` 的 `breakevens: [97.0]` 一致。
- 最大盈利：右尾斜率 `SLOPE_HIGH = (+1) + (−1) = 0`，不无界；候选点 `{0, 110}` 上取最大值为 `13`。
- 最大亏损：`SLOPE_HIGH = 0`，不无界；`S=0` 时损益 `−100 + 3 = −97`，是候选点上的最小值。
- 逐点损益：`S=90` 时 `−10 + 3 = −7`；`S=120` 时 `20 − 10 + 3 = 13`。

`example-output.json` 的对应值：`net_premium = -3.0`，`max_profit = 13.0`，`max_loss = -97.0`，`price_grid = [80, 90, 97, 100, 110, 120]`，`payoff_at_prices` 的 `profit_loss` 依次为 `-17.0, -7.0, 0.0, 3.0, 13.0, 13.0`。两条腿的 `cash_flow_at_entry` 分别为 `0.0`（期货入场无权利金流）与 `3.0`（卖出收取），相加为 `3.0 = −net_premium`。

## 买入跨式：两个盈亏平衡点

腿定义：buy call 100 @ 5；buy put 100 @ 4；数量与乘数均为 1。

- 净权利金：`+5 + 4 = 9`，即净支出 9（debit）。
- `S < 100`：call 作废损失 5；put 内在价值 `100 − S`，减权利金 4：合计 `91 − S`，零点 `S = 91`。
- `S > 100`：call 收益 `S − 100 − 5 = S − 105`；put 损失 4：合计 `S − 109`，零点 `S = 109`。
- `S = 100` 时两腿都作废：`−5 − 4 = −9`，这是候选点 `{0, 100}` 上的最小损益，即 `max_loss = -9`。
- `SLOPE_HIGH = +1 > 0`（call 多头），右尾随价格上升没有上界，所以 `max_profit = "unbounded"`；亏损一侧取 `{0, 100}` 候选点最小值，`max_loss = -9`（`S=100` 处）。

## 牛市看涨价差：有限盈亏

腿定义：buy call 100 @ 6；sell call 110 @ 2；数量与乘数均为 1。

- 净权利金：`+6 − 2 = 4`，即净支出 4（debit）。
- `S ≤ 100`：两腿都作废，损失权利金差 `−6 + 2 = −4`。
- `100 < S < 110`：多头 call 收益 `S − 100 − 6`；空头 call 保留权利金 `+2`：合计 `S − 104`，零点 `S = 104`。
- `S ≥ 110`：收益封顶 `(110 − 100) − 6 + 2 = 6`。
- `SLOPE_HIGH = +1 − 1 = 0`，右尾有限；候选点 `{0, 100, 110}` 上的最大值为 6、最小值为 −4。

## 纯空头期货：盈利有上界、亏损无界

腿定义：sell futures，入场价 100；数量 1，乘数 1；没有期权腿。

- 净权利金为 `0.0`（没有期权腿）；`cash_flow_at_entry = 0.0`。
- 到期损益 `= −(S − 100) = 100 − S`，盈亏平衡 `S = 100`。
- `SLOPE_HIGH = −1 < 0`：价格上升时亏损没有下界，因此 `max_loss = "unbounded"`。
- `max_profit` 取候选点 `{0}` 上的值 `100 − 0 = 100`：这是价格跌到 0 时的上确界，不是可成交价格，也不是 `"unbounded"`。价格定义域为 `S>0`，左尾收敛到有限极限，所以盈利一侧有界。
- 若允许负的期货结算价（如 2020 年 WTI），盈利会超过 100；本工具未建模负价格定义域，该情形需要另行扩展，不能把这里的 `100` 当成永远的风险边界。

## 领口：净支出 0.5 与真实的盈亏平衡点

腿定义：buy put 行权价 95，权利金 2；sell call 行权价 110，权利金 1.5；buy futures 入场 100；数量 1，乘数 1。

- 净权利金：`+2 − 1.5 = +0.5`，即净支出 0.5（debit）；期货腿不进入净权利金。
- `0 < S ≤ 95`：期货 `S − 100`；put `(95 − S) − 2 = 93 − S`；空头 call 保留权利金 1.5：合计 `−5.5`（常数）。
- `95 ≤ S ≤ 110`：期货 `S − 100`；put 作废损失 2；空头 call 保留 1.5：合计 `S − 100 − 2 + 1.5 = S − 100.5`。
- `S ≥ 110`：期货 `S − 100`；put 损失 2；空头 call 赔付 `S − 110` 后加权利金 1.5：合计 `S − 100 − 2 − (S − 110) + 1.5 = 9.5`。
- 因此 `max_profit = 9.5`（`S ≥ 110` 处取到），`max_loss = -5.5`（`S = 0` 与 `0 < S ≤ 95` 处取到），盈亏平衡由 `S − 100.5 = 0` 得 `S = 100.5`。

需要特别说明：把 put 行权价 95 与净支出 0.5 直接相加得到 `95.5` 的速算，忽略了期货腿相对 95 还有 5 点价内缓冲；按本 Skill 的到期损益定义，`95.5` 处损益是 `−5.0`，不是 0。以 `S − 100.5` 的代数结果为准，`example-output.json` 的 collar 场景没有被保存为文件，但这个值可由 `analyze()` 直接复算。若只凭“行权价 + 权利金”记盈亏平衡，必须同时说明标的是否已在价内；本工具不采用该速算。

## 多 kink 的精确零点

腿定义：buy call 90 @ 12；sell 2× call 100 @ 6；buy call 110 @ 2；数量与乘数均为 1。净权利金 `+12 − 12 + 2 = 2`（debit）。

- `S ≤ 90`：`−12 + 12 − 2 = −2`。
- `90 ≤ S ≤ 100`：`(S − 90) − 12 + 12 − 2 = S − 92`，零点 92。
- `100 ≤ S ≤ 110`：`(S − 90) − 12 − 2(S − 100) + 12 − 2 = 108 − S`，零点 108。
- `S ≥ 110`：`−2`；最大盈利在 `S=100` 处为 8，最大亏损为 −2。

分段区间由三个行权价切成四段，程序用解析斜率逐段求根，输出 `breakevens = [92.0, 108.0]`，不是采样近似；两个零点分别落在两个不同的 kink 区间上，用于验证“精确根”而不是网格插值。

## 不应从本例得出的结论

- 不能把 `max_profit` / `max_loss` 当成胜率、期望收益或可承受风险：没有保证金、费用、滑点、流动性与跳空，也没有概率。
- 不能把 `"unbounded"` 当成真实的无限收益；它只描述价格上升方向的线性尾部。
- 不能把 `S=0` 边界上的候选值当成可成交价格或风险下限；负期货结算价未建模。
- 不能把合成 fixture 当成真实行情或历史业绩，也不能依据策略名称下单。
- 不能把本工具输出当作对行情的预测；它只验证“腿表得到到期损益算术”的一致性。
