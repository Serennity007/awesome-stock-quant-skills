# 李录 · 价值复利投资思想整理

作者：Serennity007。本文件为对李录（喜马拉雅资本创始人）公开著作《文明、现代化、价值投资与中国》、北大价值投资课程演讲及公开访谈中投资思想的个人化学习整理。思想归属李录与喜马拉雅资本，仅供学习研究，不构成投资建议。

---

## 一、核心理念：股票是公司所有权的一部分

> **"买股票就是买公司，买公司就是买其未来现金流的折现。"**

李录把价值投资的根基归结为四条，全部来自格雷厄姆—巴菲特—芒格一脉，但他对每一条都给出了中国语境下的深化：

- **股票 = 公司所有权**：持有股票不是持有屏幕上跳动的代码，而是成为生意的部分所有者。所有研究都应该围绕"这家公司十年后值多少"展开。
- **市场先生为你服务，不指挥你**：市场波动的唯一用途是——在恐慌时把便宜筹码卖给你，在亢奋时把高估筹码买走。
- **安全边际**：只在价格显著低于内在价值时出手，为预测的不确定性留足缓冲。
- **能力圈**：知道自己知道什么、更要知道自己不知道什么。圈不在大小，边界必须清晰。

## 二、复利机器：李录对"好生意"的定义（脚本量化部分）

李录认为伟大的生意是一台**复利机器**——企业把赚到的钱再投入，仍能产生同样高甚至更高的回报。机械化近似为六维：

| 李录的标准 | 通俗解释 | 脚本对应 |
|---|---|---|
| 资本回报质量 | ROE 长期 ≥15%，说明生意本身挣钱 | `roe_mean`（25 分） |
| 复利趋势 | 近 2 年 ROE 不低于前 3 年，复利未失速 | `roe_trend_diff`（15 分） |
| 再投资成长 | 留存利润再投入仍推动两位数增长 | `profit_growth_mean`（20 分） |
| 盈利含金量 | 经营现金流与利润匹配，利润为真 | `ocf_mean`（15 分） |
| 安全边际 | PE/PB 处于自身历史低分位 | `pb_percentile`（15 分） |
| 财务纪律 | 不靠杠杆堆出来的回报 | `debt_latest`（10 分） |

### 比亚迪：复利机器的活案例

李录 2002 年研究比亚迪后重仓持有至今。"我们看中的不是某一年的利润，而是它持续把技术优势转化为竞争优势的能力"——脚本里对应的就是 ROE 质量与复利趋势两个维度；而"安全边际"则来自他买入时市值远低于对电池业务的保守估值。

## 三、真知与深度研究（无法量化、但决定一切）

- **真知即力量**：李录把知识分为"真的知道"和"自以为知道"，只投自己"真的知道"的公司。他研究一家公司常常花几个月，读全部年报、访谈客户与竞争对手。
- **少即是多**：喜马拉雅资本几十年只持有过个位数的公司。"如果一生只有 20 次打卡机会，你会谨慎得多。"
- **长期不变的东西**：预测未来最难，但有些东西几乎不变——人性的贪婪与恐惧、生意的本质逻辑。研究这些比研究风口可靠。

## 四、市场先生的正确用法

| 情形 | 李录的做法 |
|---|---|
| 好公司出现历史低分位估值 | 核查基本面是否真的没坏，没坏则分批买入 |
| 基本面变坏导致的"便宜" | 放弃——价值陷阱不是安全边际 |
| 市场狂热、持仓高估 | 持有不动，除非发现更好的标的 |
| 看不懂的机会（包括暴涨） | 与我无关，放弃 |

> "市场 95% 的时间里都在诱惑你做蠢事，你什么都不做才是对的。"

## 五、给使用者的提醒

1. **能力圈一票否决**：脚本得分再高，不属于你能力圈的公司也不要碰。这条纪律是李录体系的地基，量化无法替代。
2. **便宜有两种**：市场恐慌给的便宜（好）与基本面变坏给的便宜（坏）。重点核查复利趋势与含金量两个维度是否亮红灯。
3. **复利机器的验证在年而非季**：不要用单季度业绩推翻年度趋势判断。
4. **真正的功课在脚本之外**：脚本只是把 300 只缩到 10 只的漏斗，李录式的深度研究（全部年报、产业链访谈、管理层评估）才是决定性环节。
