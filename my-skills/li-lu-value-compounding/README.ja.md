> **「投資は未来予測のゲームであり、唯一信頼できるのは変わらないものを研究することだ。」**

本スキルは、李録（ヒマラヤ・キャピタル創業者、チャーリー・マンガーの愛弟子）のバリュー投資フレームワークをA株市場に機械化したものです：持続的な高ROE、複利トレンドの失速なし（直近2年 vs 前3年）、再投資による成長、本物のキャッシュ・イヤニング、PE/PB歴史低パーセンタイルの安全マージン、低負債の6次元スコアリング。スクリプトは候補を絞り込むだけで、「自分の能力圏内か」の判断は投資者本人の仕事です。

## 目次

- `SKILL.md` — スキル定義、6次元スコアリングロジック、使用方法
- `scripts/screen.py` — A株バリュー複利スクリーナー（CSV + 端末テーブル）
- `references/lilu_value_principles.md` — 李録の投資思想：株式=所有権、ミスター・マーケット、安全マージン、能力圏、複利マシン
- `lilu_test_result.csv` — 小サンプルのテスト出力

## クイックスタート

```bash
pip install akshare pandas

# デフォルトプール：沪深300、上位20件表示
python scripts/screen.py --pool hs300 --top 20 --out result.csv

# カスタム小サンプルテスト
python scripts/screen.py --codes 600519,000858,600036 --out result.csv
```

## パラメータ

- `--pool`：銘柄プール。現在 `hs300`（沪深300）をサポート。
- `--codes`：カンマ区切りの銘柄コード。`--pool` より優先。
- `--top`：端末に表示する上位N件（デフォルト20）。
- `--out`：CSV出力パス（デフォルト `lilu_result.csv`）。
- `--sleep`：銘柄ごとの呼び出し間隔秒数（デフォルト0.3、レート制限対策）。

## 6次元スコアリングレーダー

| 次元 | 指標 | 説明 |
|---|---|---|
| 資本リターンの質 | 5年平均ROE | ビジネス自体が稼ぐ（満点25） |
| 複利トレンド | 直近2年ROE − 前3年ROE | 複利の失速なし（満点15） |
| 再投資成長 | 純利益成長率平均 | 留保利益も稼ぐ（満点20） |
| キャッシュの質 | 営業CF/純利益 | 利潤は本物か（満点15） |
| 安全マージン | PB歴史パーセンタイル主体 | ミスター・マーケットのパニック価格（満点15） |
| 財務規律 | 最新負債比率 | 低レバレッジ（満点10） |

判定ライン：**≥75 バリュー複利候補**；**55–74 ウォッチリスト**；**<55 フレームワーク外**。
