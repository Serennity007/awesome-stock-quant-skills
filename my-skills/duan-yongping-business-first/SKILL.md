# 🏭 段永平「商业模式第一」投资法｜六维打分筛选 A 股好生意

> **"买股票就是买公司，买公司就是买它的未来现金流折现。"**

本技能把段永平的投资思想机械化落地到 A 股：不预测股价、不追题材，只用 6 把财务尺子衡量"这是不是一门好生意"——生意模式、资本回报、盈利含金量、低负债、盈利稳定、行业龙头。核心工具是 `scripts/screen.py`，它从沪深300或自定义股票池中打分排序，输出结构化 CSV，供你进一步用 `references/duan_methods.md` 做定性复核（本分、能力圈、企业文化）。

## 六维商业模式雷达（满分 100）

| 维度 | 核心问题 | 代理指标 | 权重 |
|---|---|---|---|
| 1. 生意模式 | 这是不是一门好生意？ | 近 5 年毛利率均值 + 稳定性（高且稳 = 定价权） | 25 |
| 2. 资本回报 | 公司是否持续为股东赚钱？ | 连续年度 ROE（ROIC 风格代理） | 20 |
| 3. 盈利含金量 | 利润是否变成真金白银？ | 经营现金流净额/净利润（低资本开支代理） | 20 |
| 4. 低负债 | 是否远离财务风险？ | 最新资产负债率 | 15 |
| 5. 盈利稳定 | 长期业绩是否可预期？ | 净利润（或营收）增速变异系数 | 10 |
| 6. 行业龙头 | 敢为天下后，后中争先 | 申万行业内总市值排名 | 10 |

判定线：**≥75 商业模式优秀**，进入企业文化与价格研究；**55–74 有亮点也有短板**；**<55 不符合框架**。

## 使用方法

```bash
pip install akshare pandas

# 默认用沪深300成分股作为股票池
python scripts/screen.py --pool hs300 --top 20 --out result.csv

# 或用自定义股票池（推荐先小样本验证）
python scripts/screen.py --codes 600519,000858,600036 --out result.csv
```

参数说明：

- `--pool`: 股票池，目前支持 `hs300`（沪深300）。
- `--codes`: 逗号分隔的自定义股票代码，优先级高于 `--pool`。
- `--top`: 终端展示前 N 名（默认 20）。
- `--out`: CSV 输出路径（默认 `duan_screen_result.csv`）。
- `--sleep`: 每只股票间隔秒数（默认 0.3，用于防接口限流）。

## 输出字段速览

| 字段 | 含义 |
|---|---|
| `code` / `name` / `industry` | 股票代码 / 简称 / 所处行业 |
| `total` | 商业模式综合得分（满分 100） |
| `business_score` | 生意模式得分（毛利率水平 + 稳定性） |
| `roe_score` / `roe_mean` / `roe_annual` | 资本回报得分 / 5 年 ROE 均值 / 逐年序列 |
| `cash_score` / `ocf_to_profit_mean` | 盈利含金量得分 / 经营现金流净利润比均值 |
| `debt_score` / `debt_latest` | 低负债得分 / 最新资产负债率 |
| `stability_score` | 盈利长期稳定得分 |
| `leader_score` / `ind_rank` / `ind_total` / `leader_ratio` | 行业龙头得分 / 行业内市值排名 / 行业股票数 / 市值占行业龙头比 |
| `gross_mean` / `gross_annual` | 毛利率均值 / 逐年序列 |
| `data_years` / `source` / `note` | 有效年度数 / 数据来源 / 降级说明 |

## 分析流程（配合 AI 使用）

1. **跑初筛**：运行 `screen.py` 得到候选名单与各项得分。
2. **读原则**：对照 `references/duan_methods.md`，用"本分、买股票就是买公司、商业模式第一、敢为天下后、能力圈、企业文化"六把尺子做定性复核。
3. **看人看文化**：对高分股票研究管理层是否"利润之上的追求"、有无 Stop Doing List、是否专注本职生意。
4. **估值与心态**：把股票当作非上市公司看待，用未来现金流折现的思维检查价格；能力圈外的直接放弃，"不懂不做"。

## 数据来源与降级策略

- 数据来自 `akshare` 公开接口（东方财富主要财务指标、新浪三大报表、业绩报表行业映射、腾讯全市场快照）。
- 脚本启动时默认禁用系统代理，避免 `127.0.0.1:7890` 等本地代理阻断数据源直连。
- 优先使用 `stock_financial_analysis_indicator` 获取主要财务指标；毛利率缺失时自动用新浪利润表补充；主接口失败时整体降级到新浪三大报表手工计算。
- 行业排名来自 `stock_yjbb_em` 行业映射 + 腾讯全市场快照市值，按申万行业内市值降序排名。
- 所有网络调用均带 3 次指数退避重试，调用间 `time.sleep(0.15)` 防限流。
