# 🏭 段永平「ビジネスモデル第一」投資法｜6次元スコアリングでA株の良いビジネスを発見

**[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)**

作者：Serennity007 | ライセンス：MIT | データ：akshare（東方財富・新浪・騰訊公開API）

> **「株を買うとは会社を買うことであり、会社を買うとは将来キャッシュフローの現在価値を買うことである。」**

このスキルは、段永平（ダン・ヨンピン）の投資思想をA株市場に応用します。株価予測もテーマ追跡もせず、「これは良いビジネスか？」を6つの財務指標で継続的に測定します：ビジネスモデル（粗利率の水準と安定性）、資本利益率（ROE）、利益の現金転換率、低負債、収益の安定性、業界リーダーシップ（「敢為天下後、後中争先」）。結果は構造化されたCSVで出力され、誠実さ・能力の輪・企業文化による定性的分析へつなげられます。

## ファイル一覧

- `SKILL.md` — スキル定義、6次元スコアリングロジック、使い方
- `scripts/screen.py` — A株ビジネスモデルスクリーナー（CSV + ターミナル表）
- `references/duan_methods.md` — 段永平の核心思想：株を買う=会社を買う、ビジネスモデル第一、敢為天下後、能力の輪、企業文化とStop Doing List
- `duan_test_result.csv` — 小規模テスト出力（2026-09-26、茅台/五糧液/招商銀行）

## クイックスタート

```bash
pip install akshare pandas

# デフォルト：沪深300成分銘柄を対象に、上位20銘柄を出力
python scripts/screen.py --pool hs300 --top 20 --out result.csv

# カスタムの小さな銘柄プールで検証
python scripts/screen.py --codes 600519,000858,600036 --out result.csv
```

## パラメータ

- `--pool`: 銘柄プール。現在は `hs300`（沪深300）に対応。
- `--codes`: カンマ区切りの銘柄コード。`--pool` より優先。
- `--top`: ターミナルに表示する上位N銘柄（デフォルト20）。
- `--out`: CSV出力パス（デフォルト `duan_screen_result.csv`）。
- `--sleep`: 銘柄ごとの呼び出し間隔秒数（デフォルト0.3、レート制限対策）。

## 6次元ビジネスモデルレーダー

| 次元 | 指標 | 説明 |
|---|---|---|
| ビジネスモデル | 直近5年の粗利率平均 + 変動幅 | 高くて安定=価格決定力（満点25） |
| 資本利益率 | 連続年度ROE | ROIC風プロキシ（満点20） |
| 利益の現金転換 | 営業キャッシュフロー/純利益 | 利益は現金か？（満点20） |
| 低負債 | 最新の負債比率 | 財務リスクからの距離（満点15） |
| 収益安定性 | 利益/売上成長率の変動係数 | 長期予測可能性（満点10） |
| 業界リーダー | 申万業界内時価総額ランキング | 敢為天下後、後中争先（満点10） |

判定ライン：**≥75 優れたビジネスモデル**；**55–74 長所も短所もあり**；**<55 フレームワーク外**。

## 出力フィールド

- `code` / `name` / `industry`：銘柄コード / 略称 / 業種
- `total`：総合スコア（満点100）
- `business_score` / `roe_score` / `cash_score` / `debt_score` / `stability_score` / `leader_score`：各次元スコア
- `gross_mean` / `gross_annual` / `roe_mean` / `roe_annual`：粗利率とROEの平均・年度別系列
- `ocf_to_profit_mean` / `debt_latest`：キャッシュフロー利益比平均 / 最新負債比率
- `ind_rank` / `ind_total` / `leader_ratio` / `total_mv_yi`：業界内ランキング / 業界銘柄数 / リーダー比 / 総時価総額（億元）
- `data_years` / `source` / `note`：有効年度数 / データソース / フォールバック注記

## 実測参考（2026-09-26、沪深300全銘柄300社）

山西汾酒 86点、邁瑞医療 83点、貴州茅台 82点、五糧液 81点、中国海洋石油 81点、愛美客 80点、同花順 80点、分衆伝媒 79点——高粗利率・高ROE・キャッシュカウの特徴を持つ企業が上位に集まり、「良いビジネス」の直感と一致します。
