# 🌡️ A株サイクル温度計｜ハワード・マークス ペンデュラム定位

**[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)**

作者：Serennity007 | License：MIT | データ：akshare（乐咕乐股 / 中证指数 / 東方財富 公開API）

「他人が貪欲な時に恐れ、他人が恐れている時に貪欲であれ」——その前に、市場がどこまで「熱い」または「冷たい」のか測る必要がある。本スキルはハワード・マークスのサイクル思想をA株向けの定量化ダッシュボードに落とし込む：滬深300 / 中证全指のバリュエーション分位、株式・債券収益差、出来高熱度、信用取引残高トレンドを統合し、**0-100のサイクル位置スコア**（0=極冷、100=極熱）と行動フレームワークを出力する。

## クイックスタート

```bash
pip install akshare pandas

# デフォルト：今日、10年遡り
python scripts/cycle_gauge.py

# サンプル銘柄付き
python scripts/cycle_gauge.py --codes 600519,000858,600036 --out cycle_gauge.csv

# 過去日付のテスト
python scripts/cycle_gauge.py --date 2023-12-31 --lookback 5 --out 2023_gauge.csv
```

検証環境：Python 3.11 + akshare 1.18.96 + pandas。

## パラメータ

| パラメータ | デフォルト | 説明 |
|---|---|---|
| `--date` | 今日 | レポート日。`20231231` または `2023-12-31` を受け付ける |
| `--lookback` | 10 | 历史分位の遡り年数 |
| `--codes` | — | カンマ区切りのサンプル銘柄コード（観察用） |
| `--out` | `cycle_gauge.csv` | CSV 出力パス |
| `--no-proxy` | — | 旧互換用。スクリプトは既定でプロキシを無効化済み |

> プロキシ注記：起動時に `HTTP_PROXY` / `HTTPS_PROXY` などをクリアし、ローカルプロキシ（例：`127.0.0.1:7890`）がデータ源を遮断するのを防ぐ。

## 出力フィールド

CSV は AI 解析に都合の良いロング形式：

| category | item | value | score | note |
|---|---|---|---|---|
| GAUGE | cycle_position | 総合スコア | 0-100 | 行動提言 |
| COMPONENT | valuation / spread / turnover / margin | 現在値 | 部分スコア | 計算メモ |
| INDEX | 沪深300_PE-TTM、沪深300_PB、中证全指_PE-TTM など | 現在のバリュエーション | 历史分位 | — |
| SAMPLE | コード＋名称 | 終値 / PE / PB | — | サンプル観察 |

## スコアリングロジック

- **バリュエーション（30%）**：滬深300のPE/PB、中证全指のPEの历史分位。分位が高いほど「熱い」。全市场PBは中证800のPBで近似（中证全指の历史PBは取得不可のため）。
- **株式・債券収益差（25%）**：中证全指の益利回り − 中国10年国債利回り。差が大きいほど株式が債券に対して割安＝サイクルは冷たい方向。
- **出来高熱度（25%）**：中证全指の成交金額と20日/60日移動平均の位置関係。出来高が大きいほど熱い。
- **信用取引トレンド（20%）**：全市場の融資残高の近期トレンド。上昇中は熱い。
