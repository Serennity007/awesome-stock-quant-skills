# 🌡️ A股周期温度计｜用霍华德·马克斯的钟摆给市场量体温

市场不会永远向上，也不会永远向下。本技能把霍华德·马克斯的“周期钟摆”思想机械化落地：拉取沪深300、中证全指的估值历史，计算股债收益差，观察成交额与两融余额趋势，最终合成一个 **0-100 的周期位置评分**（0=极冷，100=极热），并给出对应行动建议框架。

## 周期温度计读什么？

| 维度 | 含义 | 数据来源 |
|---|---|---|
| 估值分位 | 沪深300 PE/PB、中证全指 PE 的近 N 年历史分位 | 乐咕乐股 / 中证指数 |
| 股债收益差 | 中证全指盈利收益率 − 10年期国债收益率 | 中证指数 / 东方财富债券 |
| 成交热度 | 中证全指成交金额 vs 20日/60日均线 | 中证指数 |
| 两融余额趋势 | 全市场融资余额 vs 近期均线 | 东方财富融资融券 |

> 中证全指历史 PB 分位在公开接口中不可得，脚本自动以 **中证800 PB** 作为全市场 PB 近似，并在输出中标注。

## 使用方法

```bash
pip install akshare pandas

# 默认：今天，回看 10 年，输出 cycle_gauge.csv
python scripts/cycle_gauge.py

# 带示例个股 + 指定输出
python scripts/cycle_gauge.py --codes 600519,000858,600036 --out cycle_gauge.csv

# 历史日期回测（支持 20231231 或 2023-12-31）
python scripts/cycle_gauge.py --date 2023-12-31 --lookback 5 --out 2023_gauge.csv
```

## 参数说明

- `--date`: 报告日期，支持 `20231231` 或 `2023-12-31`（默认今天）
- `--lookback`: 历史分位回看年数（默认 10）
- `--codes`: 逗号分隔的示例个股代码，仅作观察，不参与评分
- `--out`: CSV 输出路径（默认 `cycle_gauge.csv`）
- `--no-proxy`: 兼容旧参数，现脚本已默认禁用系统代理

## 评分与行动框架

脚本输出一个综合周期位置评分（0-100）和四个分项得分：

| 综合评分 | 周期位置 | 行动框架 |
|---|---|---|
| 0-20 | 极冷 | 积极布局，逆向分批买入 |
| 20-40 | 偏冷 | 逐步建仓，保留现金 |
| 40-60 | 中性 | 持有为主，等待信号 |
| 60-80 | 偏热 | 谨慎追高，考虑减仓 |
| 80-100 | 极热 | 防御为主，控制回撤 |

权重默认：估值 30%、股债收益差 25%、成交热度 25%、两融趋势 20%。

## 配套文件

- `references/marks_memos.md` — 霍华德·马克斯核心思想整理（第二层思维、周期钟摆、逆向投资、风险观）

## 分析流程（配合 AI 使用）

1. 运行脚本，读取当前周期位置评分与分项得分。
2. 结合 `references/marks_memos.md` 做定性判断：钟摆是否已到极端？市场情绪是否过度一致？
3. **周期定位不是预测拐点**，而是识别“当前价格里包含了多少乐观/悲观”。在极端区间保留再投资能力，在平庸区间减少操作。
4. 任何评分都应结合自身风险偏好、持仓结构、现金流状况二次决策。
