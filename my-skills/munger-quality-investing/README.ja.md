# 🧠 マンガー式クオリティ投資｜A株“偉大な企業”を5次元レーダーで発見

**[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)**

作者：Serennity007 | ライセンス：MIT | データ：akshare（東方財富・新浪公開API）

> **公平な価格で偉大な企業を買うことは、安い価格で平凡な企業を買うよりも優れている。**

このスキルは、チャーリー・マンガーのクオリティ投資フレームワークをA株市場に応用します。ホットテーマの追跡も、チャート予測もせず、5つの財務指標を継続的に適用して「偉大な企業」の特徴を持つ候補を抽出します。その後、定性的分析（モート、経営陣、能力の輪）で最終判断を行います。

## ファイル一覧

- `SKILL.md` — スキル定義、5次元スコアリングロジック、使い方
- `scripts/screen.py` — A株クオリティスクリーナー（CSV + ターミナル表）
- `references/munger_checklist.md` — マンガーの多元思考モデル、逆説的思考、能力の輪、25の認知バイアス、投資チェックリスト

## クイックスタート

```bash
pip install akshare pandas

# デフォルト：沪深300成分銘柄を対象に、上位20銘柄を出力
python scripts/screen.py --pool hs300 --top 20 --out result.csv

# カスタムの小さな銘柄プールで検証
python scripts/screen.py --codes 600519,000858,600036 --out result.csv
```

## パラメータ

- `--pool`: 銘柄プール。現在は `hs300`（沪深300）をサポート。
- `--codes`: カンマ区切りのカスタム銘柄コード。`--pool` より優先される。
- `--top`: ターミナル表示する上位件数（デフォルト 20）。
- `--out`: CSV出力パス（デフォルト `munger_screen_result.csv`）。

## 5次元クオリティレーダー

| 次元 | 指標 | 説明 |
|---|---|---|
| 資本収益性 | 5年連続のROIC風指標 | akshareがROICを直接提供しないため、ROEで代理 |
| 粗利率 | 5年間の平均と安定性 | 平均>40%、変動<3ポイントが理想 |
| 低レバレッジ | 最新自己資本比率 | 30%未満で満点；金融企業は別途判断 |
| 収益の質 | 営業キャッシュフロー／純利益比率 | 平均>1.0は利益にキャッシュが伴う証拠 |
| 希薄化の少なさ | 5年間の発行済株式増加率 | 5%未満で満点；頻繁な増資には注意 |

## 出力フィールド

- `code`：銘柄コード
- `total`：総合スコア（満点100）
- `roic_score / roic_annual`：資本収益性スコア / 5年ROE系列
- `gross_score / gross_mean / gross_annual`：粗利率スコア / 平均 / 系列
- `debt_score / debt_latest`：レバレッジスコア / 最新負債比率
- `quality_score / quality_mean`：収益の質スコア / キャッシュフロー対純利益比率平均
- `dilution_score / shares_growth_pct`：希薄化スコア / 株式数増加率
- `data_years`：有効な年度数
- `source / note`：データソースとフォールバック説明
