# 🧠 芒格优质企业投资法｜5 把尺子锁定 A 股“伟大公司”

> **以公允价格买伟大公司，胜过以便宜价格买普通公司。**

本技能用查理·芒格的质量投资框架，在 A 股市场做**机械化初筛**：不预测股价，只看企业本身是否具备“伟大公司”的财务特征。核心工具是 `scripts/screen.py`——它从全市场或指定股票池中，按 5 个维度打分排序，输出结构化 CSV，供你进一步做护城河与管理层定性分析。

## 5 维质量雷达（满分 100）

| 维度 | 核心问题 | 代理指标 | 权重 |
|---|---|---|---|
| 1. 资本回报 | 公司是否为股东持续创造高回报？ | 连续 5 年 ROIC 风格指标（ROE 代理） | 25 |
| 2. 毛利率 | 生意模式是否优秀、竞争是否不激烈？ | 5 年毛利率均值与稳定性 | 25 |
| 3. 低负债 | 公司是否不依赖借钱赚钱？ | 最新资产负债率 | 15 |
| 4. 盈利质量 | 利润是否真的是现金？ | 经营现金流 / 净利润比 | 20 |
| 5. 少股本稀释 | 管理层是否在善待老股东？ | 近 5 年总股本增长幅度 | 15 |

> 注：`akshare` 公开接口未直接提供 ROIC，脚本以 ROE（净资产收益率）作为 ROIC 风格代理指标，并在输出中明确标注。

## 使用方法

```bash
pip install akshare pandas

# 默认用沪深300成分股作为股票池（质量预筛，避免全市场过慢）
python scripts/screen.py --pool hs300 --top 20 --out result.csv

# 或用自定义股票池（推荐先小样本验证）
python scripts/screen.py --codes 600519,000858,600036 --out result.csv
```

参数说明：

- `--pool`: 股票池，目前支持 `hs300`（沪深300）。
- `--codes`: 逗号分隔的自定义股票代码，优先级高于 `--pool`。
- `--top`: 终端展示前 N 名（默认 20）。
- `--out`: CSV 输出路径（默认 `munger_screen_result.csv`）。
- `--sleep`: 每只股票间隔秒数（默认 0.3，用于防接口限流）。

## 分析流程（配合 AI 使用）

1. **跑初筛**：运行 `screen.py` 得到候选名单与各项得分。
2. **读清单**：对照 `references/munger_checklist.md`，用多元思维模型、反向思考、能力圈、25 种误判倾向做自我检查。
3. **护城河定性**：对高分股票逐一判断——品牌/无形资产、成本优势、转换成本、网络效应、管理层理性。
4. **估值与仓位**：只在能力圈内、价格公允或低估时买入；真正看懂的机会敢于重注、长期持有。

## 数据来源与降级策略

- 数据来自 `akshare` 公开接口（东方财富/新浪财务数据）。
- 脚本启动时默认禁用系统代理，避免 `127.0.0.1:7890` 等本地代理阻断数据源。
- 优先使用 `stock_financial_analysis_indicator` 获取主要财务指标；若毛利率等关键字段缺失，自动用新浪三大报表补充计算；若主接口失败，整体降级到新浪三大报表。
- 所有网络调用均带 3 次指数退避重试，调用间 `time.sleep(0.15)` 防限流。

本技能仅供学习研究，不构成投资建议。历史财务指标不代表未来表现，任何筛选结果都必须经过自己对生意的理解（能力圈）二次确认。投资决策应建立在独立研究、充分安全边际与自身风险承受能力之上。
