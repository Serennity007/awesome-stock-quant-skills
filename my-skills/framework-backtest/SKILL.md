# 📊 大师框架回测验证器｜用历史数据检验大师框架在 A 股是否真的有效

> **"回测是策略的照妖镜——所有讲不出来的收益都是故事。"**

本技能把仓库里的大师框架变成**可证伪的策略**：每月末用某框架对全池打分 → 等权买入前 N 名 → 持有到下月末 → 累计净值对照沪深300。财务切片使用“报告期末 + 120 天 ≤ 调仓日”的固定滞后近似，并读取当期估值。它未核对真实披露日与历史修订版本，尚不能保证严格 point-in-time。

v1 支持三个框架：**danbin**（但斌六维，分红维度剔除后 85 分重标定）、**lilu**（李录六维）、**mom12_1**（12-1 月价格动量，作为价值框架的对照基准）。

## 已知局限（读结果前必读）

| 局限 | 影响 | 方向 |
|---|---|---|
| **幸存者偏差** | 股票池固定为当前沪深300名单，"活到今天的好公司"被系统性高估，绝对收益偏乐观 | 引入历史成分股回溯可消除 |
| 简化交易模型 | 支持成交额成本，但仍无冲击、涨跌停或停牌成交模拟；同收盘打分并成交 | 需更细粒度执行模型 |
| 非总回报 | 采用未复权价格，不含分红再投资，除权除息可能影响收益 | 需一致的总回报价格序列 |
| PE/PB 历史 | 东财接口约自 2018 年起，早期分位窗口短 | 换乐咕/其他源 |
| 年报滞后近似 | 报告期末加 120 天，不是实际披露时间，未处理历史修订 | 迟披露或重述可能引入前视信息 |

**结果仅供探索。相同偏差对不同框架的影响可能不同，框架相对排名也需要历史成分、实际披露版本与成本敏感性复核。**

## 使用方法

```bash
pip install akshare pandas numpy

# 第一步：拉取全池历史数据缓存（约 25 分钟，可断点续传，支持 --offset/--limit 分块）
python scripts/fetch_history.py --pool hs300

# 第二步：回测（默认三框架、每月等权前 10、2021-09 起）
python scripts/backtest.py

# 自定义：只跑一个框架、前 5 名、从 2023 年开始
python scripts/backtest.py --frameworks danbin --top 5 --start 2023-01-31 --out-prefix v2
```

参数说明：

- `--frameworks`: 逗号分隔，danbin / lilu / mom12_1。
- `--start`: 首个调仓月（默认 2021-09-30）。
- `--top`: 每月等权持有前 N 名（默认 10）。
- `--min-stocks`: 缓存少于该数量报错（默认 50；子集测试时调低）。
- `--out-prefix`: 输出文件名前缀。
- `--cache-dir` / `--results-dir`: 自定义缓存与输出目录，便于隔离真实数据和合成测试。
- `--cost-bps`: 每单位买卖成交额的成本基点，CLI 默认 10，可设 0；是研究假设，不是市场费率。

## 输出文件

- `results/bt_summary.csv` — 各框架净年化/基准年化/超额/最大回撤/夏普汇总
- `results/bt_result_<框架>.csv` — 月度毛净收益、毛净值、换手、成本与基准
- `results/bt_holdings_<框架>.csv` — 每期代码、权重、分数、进入/退出价格与单股收益
- `results/bt_manifest.json` — 参数、输入 CSV SHA-256、运行时间、依赖版本与未实现假设
- `results/bt_yearly_<框架>.csv` — 逐年收益对照表
- `cache/` — 个股历史数据缓存（估值/年度指标/利润表，.gitignore 排除，可随时删除重建）

## 打分口径

本回测使用独立实现的六维档位近似，不能视作各 `screen.py` 的逐项完全复刻。例如营收增长聚合、PB 安全边际的额外 PE 条件可能不同。已有的主要简化包括：

1. danbin 的"时间的玫瑰"（分红）维度剔除——历史逐股分红数据获取成本高；其余六维 85 分制重标定到 100。
2. 金融业等无毛利率行业，厚雪维度给中性 8 分（用于探索性比较，不据此宣称逐项一致）。

## 免责声明

本技能仅供学习研究，不构成投资建议。回测收益不代表未来，历史规律可能失效。

## 结果有效性

选股仅基于调仓时点的价格和可得数据。已经选中的股票若缺少退出价格，脚本会非零退出，不根据未来缺价删股后替换；基准缺失、投资期间缺月或可选股票不足也不静默补零或跳过。初始热身期可能没有足够数据，真正开始持有后必须保持月度连续。

最大回撤包含初始净值 1，因此首月亏损也计为回撤。基准保留真实交易日，按与策略相同的调仓日和退出日计算区间收益。

成本按调仓前净资产估算：旧权重先随上期价格漂移，再计算相对等权目标的买卖绝对额之和，乘以成本基点。首期建仓计费，整仓更换包含买卖两腿，期末不强制清仓。毛净收益分别保留，成本假设不替代真实成交建模。
