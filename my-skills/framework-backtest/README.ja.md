# 📊 マスター框架バックテスト検証器｜月次リバランスによる実証

**[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)**

作者：Serennity007 | ライセンス：MIT | データ：akshare（東方财富/新浪公開API）+ ローカルキャッシュ

> **「バックテストは戦略の照妖鏡——語れないリターンはただの物語だ。」**

本スキルは、リポジトリ内のマスター框架を**反証可能な戦略**に変えます：毎月末にプール全体をスコアリング → 上位N銘柄を等金額保有 → 翌月末まで → 累積純資産を滬深300と比較。財務情報の利用可能日は報告期末 +120 日で近似します。実際の開示日・過去の訂正を検証しておらず、厳密な point-in-time は保証できません。v1 は danbin（6次元）/ lilu（6次元）/ mom12_1（12-1ヶ月モメンタム・ベンチマーク）に対応。

## 目次

- `SKILL.md` — スキル定義、バックテスト仕様、使用方法
- `scripts/fetch_history.py` — 個別銘柄ヒストリカル・キャッシャー（中断再開・分割対応）
- `scripts/backtest.py` — 月次リバランス・バックテスト・エンジン
- `references/backtest_methodology.md` — 方法論：point-in-time原則、サバイバーシップ・バイアス
- `results/` — バックテスト出力
- `cache/` — データキャッシュ（.gitignore 除外）

## クイックスタート

```bash
pip install akshare pandas numpy

# ステップ1：プール履歴を取得（約25分、中断再開可）
python scripts/fetch_history.py --pool hs300

# ステップ2：3框架をバックテスト
python scripts/backtest.py
```

## 既知の限界（結果を読む前に必読）

1. **サバイバーシップ・バイアス**：ユニバースは現在の滬深300に固定——絶対リターンは系統的に美化される。**探索目的のみ。相対順位にも偏りがあり得ます**。
2. 売買額費用は設定可能（既定10 bps/単位）。衝撃・停止・値幅制限の約定は未モデル化。
3. PE/PB 履歴は約2018年以降。
4. 年報発表ラグは120日で近似。

## 実装済みの監査機能（2026-10-24）

将来の退出価格の有無で候補を先に除外せず、選択後に価格が不足したら停止します。戦略・基準の実取引日を揃え、初月損失も回撤に含めます。`--cost-bps`、`--cache-dir`、`--results-dir` を追加し、毛・純収益、変動後ウェイトの売買額、保有明細、入力ハッシュを保存。期末強制売却なし、未調整価格の制約は残ります。[SKILL.md](SKILL.md) に契約と合成例を記載。
