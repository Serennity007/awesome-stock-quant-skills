# Round 2026-11-27（第 3 轮）· F-003 年化曲线斜率 ≠ 可实现年化展期收益

- **状态**：`REFUTED`（模型级）——第 1–3 节为计算前的登记，结果见第 4–6 节
- **主张**："期货曲线年化斜率（按 365 自然日线性换算）等于持有该价差可实现的年化展期收益。"（来源：本仓库 `futures-curve-structure` 的常见误读）
- **可操作化定义**：
  - 以"滚动持有近月合约、每次移仓到下一份合约"作为"持有展期"的操作化：1 手合约，收益率分母固定为建仓时近月合约名义价值 `C0`，不做再投资。
  - "年化斜率"取仓库工具 `futures_curve.py` 的口径：`spread / last_near × 365 / days_between × 100`，只用 t0 快照的相邻两份合约。
  - "可实现的年化展期收益"取同一 t0 快照下、t0 之后 365 天内按实际移仓日结算的累计损益；现货价格恒定，损益全部来自展期，分别报告零成本与含成本。
  - 做空移仓是与正斜率（contango）同向的一侧；做多移仓是镜像方向，一并报告。
- **判定规则（计算前固定）**：
  - R1（路径判据）：同一 t0 快照、零成本、到期日移仓，三条 k 路径的做空实现毛收益极差 ≥ 5.0 个百分点。
  - R2（理想情形判据）：冻结曲线 + 到期移仓 + 零成本下，|做空实现毛收益 − 快照斜率| ≥ 0.5 个百分点。
  - R3（成本判据）：冻结曲线 + 到期移仓 + 2 bp/腿下，|做空实现净收益 − 快照斜率| ≥ 0.5 个百分点。
  - 结论映射：R1 成立 → `REFUTED`（快照斜率不能决定实现收益）；R1 不成立而 R2 或 R3 成立 → `REFUTED`（连理想/含成本口径也不"等于"）；三条都不成立 → `SUPPORTED`；若方向（做多/做空）使"等于"在符号上翻转且无法归并 → `AMBIGUOUS`。
- **说明**：同一天已有第 1 轮 `2026-11-27.md`（F-001）。为不覆盖历史轮次，本轮另存为 `2026-11-27-round3.md`；`claims.md` 中 F-003 的证据链接指向本文件。

## 1. 输入与参数

| 参数 | 值 |
|---|---|
| 数据性质 | `synthetic`：确定性生成，无随机数，不使用任何真实行情或未来数据 |
| 现货 `S(t)` | 100，全年恒定（隔离现货涨跌，只留展期损益） |
| 日期基准 `t0` | 2026-11-27（只用于到期日与 `as_of` 对齐） |
| 合约到期 | t0 后第 30/61/91/122/152/183/213/244/274/305/335/365 天，共 12 份；首尾间隔 365 天 |

| 斜率路径 `k(t)` | A 恒定 12%/年；B 从 12% 线性衰减到 0%；C 从 12% 线性上升到 24% |
| 移仓时点 | 到期日（`expiry`）或到期前 5 天（`early5`） |
| 成本 | 每腿 0 / 2 / 5 bp；每次移仓 2 条腿，全期共 24 条腿（1 次建仓 + 12 次平仓 + 11 次换月） |
| 头寸 | 做空移仓、做多移仓各算一遍；共 3 路径 × 3 成本 × 2 时点 × 2 方向 = 36 个结果，全部报告 |
| 数值精度 | IEEE-754 double，脚本不做舍入 |

## 2. 模型与公式

快照斜率（与仓库工具同式，`T1=30`、`T2=61`）：

```text
slope_01 = (F(0,T2) − F(0,T1)) / F(0,T1) × 365 / (T2 − T1) × 100
```

逐段持有与结算（第 j 段在 `t_{j-1}` 建仓、`t_j` 平仓；`side` 做空为 +1、做多为 −1）：

```text
leg_j   = side × ( F(t_{j-1}, T_j − t_{j-1}) − F(t_j, T_j − t_j) )
cost    = Σ_legs rate × notional_leg                 rate = bp / 10000
return  = ( Σ_j leg_j − cost ) / C0 × 100            C0 = F(0, 30)
```

两条恒等式用于交叉复核：

1. 冻结曲线（k 恒定）下，逐日盯市累加与逐段一次性求和的损益必须完全相等（都是同一批价格差的和）。
2. 冻结曲线、到期移仓、零成本时，做空毛收益可写成 `Σ_j SPOT · (exp(k·τ_j/365) − 1) / C0`，其中 `Σ_j τ_j = 365`。

#!/usr/bin/env python3
"""F-003: does the 365-day linear curve slope equal the realized roll return?

Synthetic, deterministic, standard-library only. No market data is used.
Inputs and decision rules are frozen in
falsification/rounds/2026-11-27-round3.md before this script is run.

Model
-----
spot S(t) = 100 constant (isolates roll from spot drift)
futures F(t,T) = S * exp(k(t) * (T - t) / 365), T = expiry in days from t0
position: 1 contract, rolled at expiry (or 5 days before), no reinvestment
return: cumulative P&L / initial front-month notional C0
"""
import argparse
import math
import sys
from datetime import date, timedelta
from pathlib import Path

SPOT = 100.0
YEAR = 365.0
T0 = date(2026, 11, 27)
EXPIRIES = [30, 61, 91, 122, 152, 183, 213, 244, 274, 305, 335, 365]
K0 = 0.12
COSTS_BP = (0, 2, 5)
TIMINGS = (("expiry", 0), ("early5", 5))


def k_static(t):
    return K0


def k_decay(t):
    return K0 * (1.0 - t / YEAR)


def k_rise(t):
    return K0 * (1.0 + t / YEAR)


PATHS = (("A_static", k_static), ("B_decay", k_decay), ("C_rise", k_rise))


def fut(t, days_left, k_fn):
    return SPOT * math.exp(k_fn(t) * days_left / YEAR)


def snapshot(k_fn):
    return [fut(0.0, T, k_fn) for T in EXPIRIES]


def slope_pct(near_px, far_px, near_days, far_days):
    return (far_px - near_px) / near_px * YEAR / (far_days - near_days) * 100.0


def simulate(k_fn, early_days, cost_bp, side):
    """Closed form per leg: P&L = sum(exit - entry); 24 traded legs in total."""
    c0 = fut(0.0, EXPIRIES[0], k_fn)
    sign = 1.0 if side == "short" else -1.0
    rate = cost_bp / 1.0e4
    pnl = 0.0
    costs = rate * c0
    entry_px = c0
    for j, T in enumerate(EXPIRIES):
        exit_t = T - early_days
        exit_px = fut(exit_t, early_days, k_fn)
        pnl += sign * (entry_px - exit_px)
        costs += rate * exit_px
        if j + 1 < len(EXPIRIES):
            entry_px = fut(exit_t, EXPIRIES[j + 1] - exit_t, k_fn)
            costs += rate * entry_px
    return (pnl - costs) / c0 * 100.0, pnl / c0 * 100.0, costs / c0 * 100.0


def simulate_daily(k_fn, early_days, cost_bp, side):
    """Same quantity, accumulated by daily mark-to-market instead of one shot."""
    c0 = fut(0.0, EXPIRIES[0], k_fn)
    sign = 1.0 if side == "short" else -1.0
    rate = cost_bp / 1.0e4
    pnl = 0.0
    costs = 0.0
    start = 0
    for j, T in enumerate(EXPIRIES):
        entry_px = fut(start, T - start, k_fn)
        costs += rate * entry_px
        exit_t = T - early_days
        prev = entry_px
        for day in range(start + 1, exit_t + 1):
            cur = fut(day, T - day, k_fn)
            pnl += sign * (prev - cur)
            prev = cur
        costs += rate * prev
        start = exit_t
    return (pnl - costs) / c0 * 100.0


def main(argv=None):
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--repo", default=".", help="repository root for the futures-curve tool")
    args = parser.parse_args(argv)

    snap = snapshot(k_static)
    c0 = snap[0]
    tool_slope = tool_total = float("nan")
    try:
        sys.path.insert(0, str(Path(args.repo).resolve() / "my-skills" / "futures-curve-structure" / "scripts"))
        from futures_curve import analyze

        rows = ["contract,expiry,last"]
        for j, T in enumerate(EXPIRIES):
            rows.append(",".join(("F%02d" % (j + 1), (T0 + timedelta(days=T)).isoformat(), repr(snap[j]))))
        result = analyze("\n".join(rows) + "\n", "F003_SYNTH", T0.isoformat())
        tool_slope = result["adjacent_spreads"][0]["annualized_slope_pct"]
        tool_total = result["structure"]["total_annualized_change_pct"]
        tool_note = "%d contracts, %s" % (len(result["curve"]), result["structure"]["classification"])
    except Exception as exc:  # tool missing -> keep going, mark the cross-check as failed
        tool_note = "UNAVAILABLE: %r" % (exc,)

    pair_slope = slope_pct(snap[0], snap[1], EXPIRIES[0], EXPIRIES[1])
    total_slope = slope_pct(snap[0], snap[-1], EXPIRIES[0], EXPIRIES[-1])
    diff = max(abs(pair_slope - tool_slope), abs(total_slope - tool_total))

    print("Python %s | t0=%s | S=%.1f | k0=%.4f/yr | C0=%.10f | legs=24"
          % (sys.version.split()[0], T0, SPOT, K0, c0))
    print()
    print("[1] snapshot annualized slope (%)")
    print("  slope_pair01     = %.6f" % pair_slope)
    print("  slope_first_last = %.6f" % total_slope)
    print("  repo_tool_pair01 = %.6f  (%s)" % (tool_slope, tool_note))
    print("  repo_tool_total  = %.6f" % tool_total)
    print("  max_abs_diff_pp  = %.3e" % diff)
    print()
    print("[2] realized return, % of initial notional (net = after cost)")
    print("  path      cost_bp  timing   short_gross  short_net   long_gross   long_net")
    for name, fn in PATHS:
        for cost_bp in COSTS_BP:
            for tname, early in TIMINGS:
                short_net, short_gross, _ = simulate(fn, early, cost_bp, "short")
                long_net, long_gross, _ = simulate(fn, early, cost_bp, "long")
                print("  %-9s %7d  %-7s  %11.4f  %9.4f  %11.4f  %9.4f"
                      % (name, cost_bp, tname, short_gross, short_net, long_gross, long_net))
    print()
    print("[3] same snapshot, zero cost, expiry roll (short side)")
    vals = []
    for name, fn in PATHS:
        net, gross, _ = simulate(fn, 0, 0, "short")
        vals.append(gross)
        print("  %-9s short_gross=%9.4f pp   long_gross=%9.4f pp" % (name, gross, -gross))
    print("  range=%.4f pp (min %.4f, max %.4f)" % (max(vals) - min(vals), min(vals), max(vals)))
    a_gross = simulate(k_static, 0, 0, "short")[1]
    a_net2 = simulate(k_static, 0, 2, "short")[0]
    print("  R1_range_pp = %.4f  (rule: >= 5.0 -> %s)"
          % (max(vals) - min(vals), "yes" if max(vals) - min(vals) >= 5.0 else "no"))
    print("  R2_gap_pp   = %.4f  (A gross vs slope_pair01; rule: >= 0.5 -> %s)"
          % (abs(a_gross - pair_slope), "yes" if abs(a_gross - pair_slope) >= 0.5 else "no"))
    print("  R3_gap_pp   = %.4f  (A net 2bp vs slope_pair01; rule: >= 0.5 -> %s)"
          % (abs(a_net2 - pair_slope), "yes" if abs(a_net2 - pair_slope) >= 0.5 else "no"))
    print()
    print("[4] cross-check: closed-form leg sum vs daily mark-to-market (pp)")
    worst = 0.0
    for name, fn in PATHS:
        for cost_bp in COSTS_BP:
            for tname, early in TIMINGS:
                for side in ("short", "long"):
                    closed = simulate(fn, early, cost_bp, side)[0]
                    daily = simulate_daily(fn, early, cost_bp, side)
                    worst = max(worst, abs(closed - daily))
    print("  max_abs_diff_pp = %.3e  (36 combinations)" % worst)
    print()
    print("[5] snapshot csv (for the repo tool)")
    print("contract,expiry,last")
    for j, T in enumerate(EXPIRIES):
        print("F%02d,%s,%r" % (j + 1, (T0 + timedelta(days=T)).isoformat(), snap[j]))
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

PY

## 5. 交叉验证

1. **快照斜率（仓库工具 vs 解析式）**：脚本把同一组 12 份合约价格写成 CSV 交给仓库的 `futures_curve.analyze()`，相邻首对 `annualized_slope_pct = 12.061359`、首末 `total_annualized_change_pct = 12.685765`，与脚本内解析式逐位一致（`max_abs_diff_pp = 0.000e+00`），分类 `contango`。手算复核：`(exp(0.12×31/365) − 1) × 365/31 = 12.0614%`。
2. **实现收益（逐段求和 vs 逐日盯市）**：同一个量用两种独立路径计算——逐段一次性结算（闭式）与逐日盯市累加 365 天——在全部 36 个组合上差 **0.000e+00 pp**。
3. **首跑修正记录**：第一次运行时，逐日盯市函数把做空方向符号写反、并漏记了 11 次换月的建仓腿成本，交叉复核显示 35.47 pp 的差异。修正后差异归零；主结果（第 4 节 [2][3]）由逐段求和函数产生，修正前后数字完全一致。主张、参数与判定规则（第 1–2 节）在运行前固定，未因结果改动。

## 6. 结论

**判定：`REFUTED`（模型级——在写明的合成口径下，"年化斜率 = 可实现年化展期收益"不成立）。**

按预登记判据逐条对照：

| 判据 | 门槛 | 实测 | 是否成立 |
|---|---|---|---|
| R1 路径极差（零成本、到期移仓、做空） | ≥ 5.0 pp | 11.0012 pp | **是** |
| R2 理想情形差（A、0 bp） | ≥ 0.5 pp | 0.1195 pp | 否 |
| R3 含成本差（A、2 bp/腿） | ≥ 0.5 pp | 0.5972 pp | **是** |

- 同一 t0 快照（斜率 12.0614%）下，零成本、到期移仓的做空实现毛收益为 **6.46%–17.46%**，只由斜率未来怎么演化决定；成本再加 **0.48–1.19 pp** 的拖累。因此"等于"不成立：年化斜率是单点快照描述，不是可实现收益的估计。
- 最接近"相等"的只有一个刀锋情形：曲线斜率在整个持有期冻结、到期移仓、零成本，差 0.12 pp（分母口径与线性/求和的差异）。一旦斜率变化（B/C），偏差变成 **−5.60 pp / +5.40 pp**，这不是舍入误差。
- 斜率本身不含方向信息：同一快照下做多移仓是 **−11.9419%**。要谈"等于"，必须先说明头寸方向；否则符号都可能反。

**本轮没有证明**：展期策略有效或无效、任何真实品种的曲线会怎样演化、真实市场里年化斜率对后续收益有没有预测力。这条判定是模型/会计层面的（两个定义不同的量不会自动相等），不是经验结论。

## 7. 边界与未证明的部分

- 全部输入为 `synthetic`：现货恒定 100、曲线严格服从 `exp(k(t)(T−t)/365)`、成本按名义价值的固定 bp 计。没有使用任何真实行情、未来数据或供应商数据。
- 现货恒定是为了隔离展期损益；真实总收益 = 现货涨跌 + 展期，本轮只测后者。
- 三条 k 路径是三个确定性剧本，用来展示"同一快照、不同结果"，不是对曲线演化的预测或分布，11 pp 极差也不能当成收益区间估计。
- 未建模：保证金与资金占用、每日结算的资金时间价值、交割与移仓规则差异、买卖价差随流动性的变化、冲击成本、税费、合约乘数与单位。
- 头寸为 1 手、不复利，收益率分母固定为建仓时近月名义价值；换成复利或保证金口径，数字会变，但"路径决定结果"的结论不变（未在本轮逐一验证）。
- 未测其他移仓规则（按成交量/持仓量移仓、连续合约编制）与实盘执行偏差。
