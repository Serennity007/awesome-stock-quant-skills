# Round 2026-11-27（第 4 轮）· F-008 RSI<30 之后 5 个交易日的正收益概率

- **状态**：登记（计算前写入；结果见第 4–6 节）
- **主张**："RSI < 30 的'超卖'状态之后，短期（如 5 个交易日）正收益概率显著高于 50%。"（来源：常见技术分析经验）
- **可操作化定义**：
  - 固定 30 只大市值 A 股（列表在脚本 `SYMBOLS`，2026-11-27 时点选定，非随机抽样），2018-01-01 至 2026-11-27 的前复权日线；每只剔除上市后前 60 个交易日。
  - RSI 用 Wilder 14 日、收盘价。信号日 t 指收盘后 RSI(14) < 30；t+1 开盘买入，t+5 收盘卖出（5 个交易日）；单笔收益 `ret = close[t+5] / open[t+1] − 1`，`ret > 0` 记为一次正收益。
  - "显著高于 50%"用单侧检验、5% 水平；推断单元不是单笔交易，而是交易日（同一天多只股票同时触发高度相关，5 日窗口又互相重叠）。
  - 基准不是 50%，而是同一股票池、同一区间、同一买卖口径下**所有可交易日**的正收益概率 `p_base`；另报 `diff = p_event − p_base`。
- **判定规则（计算前固定）**：
  - R1a：主组合（RSI 阈值 30、持有 5 日、零成本）的 `p_event` 单侧 95% 下界 > 0.5（等价于块 bootstrap 的 `p1 ≤ 0.05`）。
  - R1b：主组合 `p1` 经 9 组（阈值 {20,30,40} × 持有期 {3,5,10}）Holm 校正后 ≤ 0.05。
  - R2：主组合零成本的 `diff` 单侧 95% 下界 > 0（`p2 ≤ 0.05`），即 RSI 相对无条件基准有增量信息。
  - R3：主组合扣 0.15% 双边成本后，`p_event` 单侧 95% 下界仍 > 0.5。
  - 结论映射：
    - R1a 不成立 → `REFUTED`（"显著高于 50%"在依赖结构下不成立）。
    - R1a 成立、R1b 不成立 → `AMBIGUOUS`（结论依赖多重比较校正）。
    - R1a 与 R1b 成立 → `SUPPORTED`（字面主张）；R2 不成立记"无增量信息"，R3 不成立记"扣成本后不成立"，都写入边界。
    - 朴素检验（iid Wilson/z）与块 bootstrap 在 5% 水平上结论相反且无法用依赖结构解释 → `AMBIGUOUS`。
- **说明**：同日已有第 1 轮 `2026-11-27.md`（F-001）与第 3 轮 `2026-11-27-round3.md`（F-003）；F-002 仍是 `BLOCKED`，没有轮次文件。为避免覆盖历史轮次，本轮另存为 `2026-11-27-round4.md`。
- **数据口径修正（首跑后、结果采信前）**：首跑用 `fqt=1` 前复权，发现 601088 在 2017 至 2020-07 的前复权价 ≤ 0（累计现金分红超过早期价格）、300750 上市首两日为负；负价格让 `close/open` 比率失去意义，该次运行作废。改用 `fqt=2` 后复权重跑；股票池、区间、阈值、基准与判定规则均不变。

| RSI | Wilder 14 日，收盘价；`avg_loss = 0` 时 RSI 记 100 |
| 成交口径 | 信号日 t 收盘后计算；t+1 开盘买入；t+5 收盘卖出 |
| 成本 | 0 bp（主张原文）、15 bp、30 bp 双边 |

| 依赖处理 | 按交易日循环块 bootstrap：块长 10 个交易日、2000 次重采样、固定种子 20261127 |
| 多重比较 | 9 组单侧 p 值的 Holm 校正 |
| 数值精度 | IEEE-754 double；p 值最小分辨率 1/2001 ≈ 0.0005 |

## 2. 统计量与检验

```text
RSI_t   = 100 − 100 / (1 + avg_gain_t / avg_loss_t)        # Wilder 平滑，14 日
ret_i   = close[t+5] / open[t+1] − 1                        # 单笔，含 0 成本
p_event = #{ret_i > 0} / N_event
p_base  = #{ret_i > 0} / N_base                             # 同池、同期、同口径的所有日
diff    = p_event − p_base
```

- 块 bootstrap：把全样本交易日排成日历，按 10 个连续交易日一块做循环重采样（块数 = ⌈D/10⌉），每块内保留当天全部股票的事件与基准单元；重复 2000 次，得到 `p_event`、`p_base`、`diff` 的抽样分布与 95% 区间。块长 10 ≥ 最长持有期 10，用来保留同一信号日内的横截面相关与 5 日窗口重叠。
- 单侧 p 值取重采样分布中 `p_event ≤ 0.5`（对应 R1）与 `diff ≤ 0`（对应 R2）的比例；与区间同源，避免两种口径混用。
- 朴素对照：Wilson 95% 区间与单笔二项 z 检验，只用于展示"忽略依赖"会把显著性放大多少，不作为判定依据。

#!/usr/bin/env python3
"""F-008: does RSI(14) < 30 raise the 5-day positive-return probability above 50%?

Standard-library-only panel test on 30 fixed A-share large caps.
Daily back-adjusted (hfq, fqt=2) bars come from the Eastmoney kline endpoint;
the first qfq run was discarded because forward-adjusted prices went negative
for high-dividend names. Nothing is committed from the vendor except summary
numbers and hashes (see the round record).
Design and decision rules are frozen in
falsification/rounds/2026-11-27-round4.md before this script is run.
"""
import hashlib
import json
import math
import random
import time
from urllib.parse import urlencode
from urllib.request import Request, urlopen

SYMBOLS = [
    "600519", "300750", "600036", "601318", "000858", "600900", "000333", "002594",
    "601398", "601857", "601288", "601988", "600028", "601088", "600276", "603259",

PANEL_START = "20170101"
EVENT_START = "2018-01-01"
WARMUP = 60           # bars dropped after listing / before the sample starts
PERIOD = 14           # Wilder RSI period
THRESHOLDS = (20, 30, 40)
HORIZONS = (3, 5, 10)
PRIMARY = (30, 5)
COST_BPS = (0.0, 15.0, 30.0)   # round-trip cost, basis points of notional
BLOCK = 10            # calendar days per bootstrap block (>= max horizon)
REPS = 2000
SEED = 20261127
BASE = "https://push2his.eastmoney.com/api/qt/stock/kline/get"


def secid(code):
    return ("1." if code.startswith("6") else "0.") + code


def fetch(code, tries=3):
    params = {"secid": secid(code), "fields1": "f1,f2,f3", "fields2": "f51,f52,f53",
              "klt": "101", "fqt": "2", "beg": PANEL_START, "end": "20500101"}
    url = BASE + "?" + urlencode(params)
    last = None
    for attempt in range(tries):
        try:
            req = Request(url, headers={"User-Agent": "Mozilla/5.0"})
            with urlopen(req, timeout=30) as resp:
                payload = json.loads(resp.read().decode("utf-8"))
            klines = payload["data"]["klines"]
            rows = []
            for line in klines:
                d, o, c = line.split(",")[:3]
                rows.append((d, float(o), float(c)))
            if any(o <= 0.0 or c <= 0.0 for _, o, c in rows):
                raise ValueError("non-positive adjusted price")
            if len(rows) < 300:
                raise ValueError("too few rows: %d" % len(rows))
            return rows
        except Exception as exc:  # network / vendor error -> retry with backoff
            last = exc
            time.sleep(1.0 + attempt)
    raise RuntimeError("%s: %s" % (code, last))


def rsi_wilder(closes, period=PERIOD):
    """Wilder RSI; None before the first full window. avg_loss == 0 -> 100."""
    n = len(closes)
    out = [None] * n
    if n <= period:
        return out
    gains = losses = 0.0
    for i in range(1, period + 1):
        ch = closes[i] - closes[i - 1]
        gains += max(ch, 0.0)
        losses += max(-ch, 0.0)
    ag, al = gains / period, losses / period
    out[period] = 100.0 if al == 0.0 else 100.0 - 100.0 / (1.0 + ag / al)
    for i in range(period + 1, n):
        ch = closes[i] - closes[i - 1]
        ag = (ag * (period - 1) + max(ch, 0.0)) / period
        al = (al * (period - 1) + max(-ch, 0.0)) / period
        out[i] = 100.0 if al == 0.0 else 100.0 - 100.0 / (1.0 + ag / al)
    return out


def collect(frames, thr, horizon):
    """Return [(signal_date, gross_return)] for events and for every eligible day."""
    events, base = [], []
    for dates, opens, closes, rsis in frames.values():
        n = len(dates)
        for i in range(WARMUP, n - horizon):
            if dates[i] < EVENT_START:
                continue
            entry = opens[i + 1]
            if entry <= 0.0:
                continue
            ret = closes[i + horizon] / entry - 1.0
            base.append((dates[i], ret))
            r = rsis[i]
            if r is not None and r < thr:
                events.append((dates[i], ret))
    return events, base


def daily_agg(events, base, cost):
    """Per-date [event_count, event_pos, base_count, base_pos] after `cost`."""
    agg = {}
    for d, r in base:
        a = agg.setdefault(d, [0, 0, 0, 0])
        a[2] += 1
        a[3] += 1 if r - cost > 0.0 else 0
    for d, r in events:
        a = agg.setdefault(d, [0, 0, 0, 0])
        a[0] += 1
        a[1] += 1 if r - cost > 0.0 else 0
    return agg


def bootstrap(agg, calendar):
    """Circular block bootstrap over trading dates; returns (p_event, p_base) pairs."""
    d = len(calendar)
    arrays = [[agg[day][k] if day in agg else 0 for day in calendar] for k in range(4)]
    bsum = [[0] * d for _ in range(4)]
    for s in range(d):
        for k in range(4):
            arr = arrays[k]
            bsum[k][s] = sum(arr[(s + j) % d] for j in range(BLOCK))
    blocks = (d + BLOCK - 1) // BLOCK
    rng = random.Random(SEED)
    out = []
    for _ in range(REPS):
        ev = pg = bc = bg = 0
        for _ in range(blocks):
            s = rng.randrange(d)
            ev += bsum[0][s]
            pg += bsum[1][s]
            bc += bsum[2][s]
            bg += bsum[3][s]
        out.append((pg / ev, bg / bc))
    return out


def pct(values, q):
    ordered = sorted(values)
    idx = min(len(ordered) - 1, max(0, int(round(q * (len(ordered) - 1)))))
    return ordered[idx]


def z_one_sided(p, n):
    return 0.5 * math.erfc((p - 0.5) * math.sqrt(n) / math.sqrt(0.25) / math.sqrt(2.0))


def wilson(p, n, z=1.959963984540054):
    denom = 1.0 + z * z / n
    centre = (p + z * z / (2.0 * n)) / denom
    half = z * math.sqrt(p * (1.0 - p) / n + z * z / (4.0 * n * n)) / denom
    return centre - half, centre + half


def main():
    frames, panel_lines, missing = {}, [], []
    for code in SYMBOLS:
        try:
            rows = fetch(code)
        except RuntimeError as exc:
            missing.append(str(exc))
            continue
        frames[code] = ([r[0] for r in rows], [r[1] for r in rows],
                        [r[2] for r in rows], rsi_wilder([r[2] for r in rows]))
        for d, o, c in rows:
            panel_lines.append("%s,%s,%.6f,%.6f" % (code, d, o, c))
        print("  %s rows=%d %s..%s" % (code, len(rows), rows[0][0], rows[-1][0]))
        time.sleep(0.25)

    print("[1] panel symbols=%d missing=%d" % (len(frames), len(missing)))
    for item in missing:
        print("  MISSING", item)
    sha = hashlib.sha256(("\n".join(sorted(panel_lines)) + "\n").encode("utf-8")).hexdigest()
    print("  sha256(panel) = %s" % sha)

    prim_events, prim_base = collect(frames, PRIMARY[0], PRIMARY[1])
    combos = []
    for thr in THRESHOLDS:
        for horizon in HORIZONS:
            events, base = collect(frames, thr, horizon)
            calendar = sorted({d for d, _ in base})
            gross = daily_agg(events, base, 0.0)
            net = daily_agg(events, base, COST_BPS[1] / 1.0e4)
            combos.append({"thr": thr, "h": horizon, "events": len(events),
                           "base": len(base), "dates": len({d for d, _ in events}),
                           "boot": bootstrap(gross, calendar),
                           "boot_net": bootstrap(net, calendar),
                           "p_ev": sum(1 for _, r in events if r > 0) / len(events),
                           "p_base": sum(1 for _, r in base if r > 0) / len(base),
                           "p_ev_net": sum(1 for _, r in events if r - COST_BPS[1] / 1.0e4 > 0) / len(events),
                           "p_base_net": sum(1 for _, r in base if r - COST_BPS[1] / 1.0e4 > 0) / len(base)})

    print()
    print("[2] primary thr=%d horizon=%d  (gross and net of %.0f bp round trip)"
          % (PRIMARY[0], PRIMARY[1], COST_BPS[1]))
    prim = [c for c in combos if (c["thr"], c["h"]) == PRIMARY][0]
    print("  events=%d  unique_signal_dates=%d  base_cells=%d"
          % (prim["events"], prim["dates"], prim["base"]))
    print("  p_event_gross   = %.6f" % prim["p_ev"])
    print("  p_base_gross    = %.6f" % prim["p_base"])
    print("  diff_gross      = %.6f" % (prim["p_ev"] - prim["p_base"]))
    print("  p_event_net     = %.6f" % prim["p_ev_net"])
    print("  p_base_net      = %.6f" % prim["p_base_net"])
    print("  diff_net        = %.6f" % (prim["p_ev_net"] - prim["p_base_net"]))
    for label, pair in (("gross", prim["boot"]), ("net", prim["boot_net"])):
        pe = [b[0] for b in pair]
        pb = [b[1] for b in pair]
        print("  %s boot 95%% CI p_event=[%.6f, %.6f]  p_base=[%.6f, %.6f]  diff=[%.6f, %.6f]"
              % (label, pct(pe, 0.025), pct(pe, 0.975), pct(pb, 0.025), pct(pb, 0.975),
                 pct([b[0] - b[1] for b in pair], 0.025), pct([b[0] - b[1] for b in pair], 0.975)))
        p1 = (sum(1 for b in pair if b[0] <= 0.5) + 1) / (REPS + 1)
        p2 = (sum(1 for b in pair if b[0] - b[1] <= 0.0) + 1) / (REPS + 1)
        print("  %s one-sided boot p(p_event<=0.5)=%.4f  p(diff<=0)=%.4f" % (label, p1, p2))
    lo, hi = wilson(prim["p_ev"], prim["events"])
    print("  naive Wilson 95%% CI p_event=[%.6f, %.6f]" % (lo, hi))
    print("  naive one-sided z vs 50%%: p=%.4f" % z_one_sided(prim["p_ev"], prim["events"]))

    print()
    print("[3] 9 combinations (gross; Holm over the 9 one-sided bootstrap p-values)")
    rows = []
    for c in combos:
        p1 = (sum(1 for b in c["boot"] if b[0] <= 0.5) + 1) / (REPS + 1)
        p2 = (sum(1 for b in c["boot"] if b[0] - b[1] <= 0.0) + 1) / (REPS + 1)
        rows.append((c, p1, p2))
    print("  thr  h  events  dates   p_event   p_base    diff     boot_p1  boot_p2")
    for c, p1, p2 in rows:
        print("  %3d %3d %7d %6d  %8.4f  %8.4f  %+8.4f  %7.4f  %7.4f"
              % (c["thr"], c["h"], c["events"], c["dates"], c["p_ev"], c["p_base"],
                 c["p_ev"] - c["p_base"], p1, p2))
    for label, idx in (("p1", 1), ("p2", 2)):
        ordered = sorted((r[idx], r[0]["thr"], r[0]["h"]) for r in rows)
        print("  Holm(%s): " % label, end="")
        prev = 0.0
        for k, (p, thr, h) in enumerate(ordered):
            adj = max(prev, min(1.0, p * (9 - k)))
            prev = adj
            print("(%d,%d)=%.4f " % (thr, h, adj), end="")
        print()
    print()
    print("[4] primary net 0.15% and 0.30%")
    for bps in COST_BPS:
        cost = bps / 1.0e4
        p_ev = sum(1 for _, r in prim_events if r - cost > 0) / len(prim_events)
        p_be = sum(1 for _, r in prim_base if r - cost > 0) / len(prim_base)
        print("  cost=%.0f bp  p_event=%.6f  p_base=%.6f  diff=%+.6f"
              % (bps, p_ev, p_be, p_ev - p_be))
    print()
    print("[5] RSI spot checks (600519)")
    dates, opens, closes, rsis = frames["600519"]
    for i in (0, 100, len(dates) - 1):
        print("  %s open=%.4f close=%.4f rsi=%s"
              % (dates[i], opens[i], closes[i], "None" if rsis[i] is None else "%.6f" % rsis[i]))
    print("  first_valid_rsi_index=%d date=%s rsi=%.6f"
          % (PERIOD, dates[PERIOD], rsis[PERIOD]))
    return 0

## 5. 交叉验证

1. **独立实现复算**：`verify4b.py` 复用同一抓取函数，但 RSI、事件筛选、基准与 9 组参数全部用 pandas/numpy 重写（与主脚本的列表/循环实现是两条代码路径），主组合得到 `n_ev=2571, n_base=64236, p_ev=0.556204, p_base=0.498038, diff=+0.058165`，与主脚本逐位一致；9 组的事件数、基准数与两个概率也全部一致。
2. **RSI 实现**：pandas `ewm(alpha=1/14)` 与主脚本的 Wilder 平滑在 2026-11-27 同为 61.1285（差 1e-6）；2017-06-06 相差 0.077，来自初始化（简单平均 vs 首值），随时间衰减，不影响 2018 年后的信号。
3. **原始价格**：东财 `fqt=0` 收盘价与 akshare 未复权收盘价逐位一致（600519 2026-11-27 = 1472.36、2018-06-05 = 788.05；000858 2026-11-27 = 72.55）。
4. **复权口径**：东财 hfq 与 akshare hfq 的 600519 区间总收益比同为 **2.177824**，说明两套后复权序列一致；主结果使用 hfq 正是为了避开前复权负价。
5. **数据口径事故（qfq 首跑作废）**：首次运行用 `fqt=1` 前复权，601088 在 2017 至 2020-07 的前复权价 ≤ 0（现金分红累计超过早期价格）、300750 上市首两日为负。该次运行有 16 个基准单元的建仓价 ≤ 0、其中 5 个落在信号内，`close/open` 比率失去意义，结果作废（仅记录：`p_event=0.555556, p_base=0.497804, events=2565`）。改用 `fqt=2` 后复权后，负价消失，正文数字全部来自后复权。
6. **重采样稳定性**：主组合 p1 在 2000 次块 bootstrap、不同种子下为 0.0040–0.0080，对应 Holm 0.036–0.072，跨过 0.05。预登记种子（20261127）给 0.0585，未过线；但"校正后是否显著"落在重采样噪声带内，这一点写进结论而不是掩盖。

## 6. 结论

**判定：`AMBIGUOUS`（经验级——样本内方向一致，但"显著高于 50%"是否成立取决于多重比较校正与成本口径）。**

按预登记判据逐条对照：

| 判据 | 门槛 | 实测 | 是否成立 |
|---|---|---|---|
| R1a 主组合零成本，对 50% 的单侧检验 | p ≤ 0.05 | 0.0065 | **是** |
| R1b 主组合经 9 组 Holm 校正 | p ≤ 0.05 | **0.0585** | **否** |
| R2 主组合相对无条件基准（diff > 0） | p ≤ 0.05 | 0.0020（Holm 0.0180） | **是** |
| R3 扣 15 bp 双边成本后对 50% | 95% 下界 > 0.5 | 下界 0.4971，p1 0.0330 | **否** |

- **点估计的方向是清楚的**：RSI(14)<30 之后 5 个交易日的正收益概率为 **55.6%**（944 个信号日、2571 笔），无条件基准 **49.8%**，差 **+5.8pp**；这个差在块 bootstrap 下 p=0.002，即使做 9 组 Holm 校正后仍是 0.018。样本内"超卖后短期正收益概率更高"这一点，没有在本轮被推翻。
- **但"显著高于 50%"这句话不稳健**：9 组多重比较校正后 p=0.0585，刚过不了 5%；扣 15 bp 双边成本后，95% 下界降到 0.4971，连"高于 50%"也不成立（`p_event` 降到 54.2%，`p_base` 降到 48.2%，差值仍是 +6.0pp）。也就是说，交易成本几乎正好吃掉"50%"这条线之外的余量。
- **为什么 R2 过、R1b 不过**：基准 49.8% 略低于 50%，检验"高于基准"比检验"高于 50%"容易；两者的 p 值差约 3 倍，9 倍校正后一个过线、一个不过。这不是矛盾，而是说明主张的参照点（50%）本身选得随意。
- 朴素 Wilson 区间是 [0.5369, 0.5753]、二项 z 检验 p≈0.0000，看起来"非常显著"；块 bootstrap 把区间拉宽到 [0.5122, 0.5992]，p 变成 0.0065。忽略同日多股相关与 5 日窗口重叠，会把证据放大一个量级——这是本轮方法上的主要发现之一。

**本轮没有证明**：RSI 是"有效指标"、任何交易策略能盈利、这个概率差在其他市场/时段/股票池仍然成立。正收益概率高于 50% 不等于期望收益为正（未报平均收益与盈亏比），也不构成交易建议。

## 7. 边界与未证明的部分

- **样本**：30 只 2026-11-27 时点的大市值 A 股，2018-01-01 至 2026-11-27，单一行情区间；不是随机样本，也不含退市股，存在幸存者/选择偏差。条件与无条件在同一池内比较可以缓解、但不能消除该偏差。
- **依赖结构**：944 个信号日、2571 笔交易、5 日窗口重叠；块 bootstrap（块长 10）只是对相关结构的近似，没有建模波动率聚集与横截面因子。
- **成本**：15 bp / 30 bp 是粗略量级（佣金、印花税、滑点），未建模冲击成本、涨跌停无法成交、停牌与 T+1 细节；A 股 T+1 在本口径下可执行（t+1 买、t+5 卖）。
- **参数**：RSI 只用 14 日、Wilder 平滑；入场用次日开盘，未测收盘价入场、止盈止损、分批建仓。
- **推断**：全部是样本内估计，没有样本外或滚动窗口检验；9 组参数是事先登记的家族，Holm 校正偏保守（9 组高度相关），但没有改用更复杂的方法来"救"结论。
- **未证明**：任何可交易策略的收益、其他市场（美股/期货/加密）的同类效应、更长或更短持有期、其他 RSI 阈值下的稳健性（只报了 9 组）。
