- **可操作化定义**：
  - 给定一条日简单收益序列 `r_1 … r_n`：算术年化 `A = 252 × mean(r)`；复合年化 `C = (∏(1+r_i))^(252/n) − 1`；差 `gap = A − C`。
  - "等于"指对任意非退化序列 `gap = 0`，或在实际数据上小到可以忽略；本轮不预设 gap 的符号。
  - 三段检验：确定性反例（可直接手算）→ 对数正态解析 + 蒙特卡洛（验证机制与量级）→ 30 只 A 股后复权日线（量级）。
- **判定规则（计算前固定）**：
  - R1：存在一条 252 日的可构造序列，使 `|gap| ≥ 10 个百分点`（或算术年化与复合年化符号相反）→ 主张不成立。
  - R2：对数正态蒙特卡洛的 gap 与解析值之差 ≤ 0.5 pp（验证实现），且 `|gap| ≥ 1 pp`（偏离不是舍入）。
  - R3：30 只股票中 `|gap| > 0` 的比例为 100%，且 gap 中位数的绝对值 ≥ 2 pp。
  - 结论映射：R1 成立 → `REFUTED`（模型级——反例即可推翻"恒等"）；R1 不成立而 R2/R3 成立 → 仍 `REFUTED`（实际量级不可忽略）；三条都不成立 → `SUPPORTED`。

## 2. 数学关系

```text
A = 252 · mean(r)
C = exp( 252 · mean( log(1+r) ) ) − 1
gap = A − C
```

- 对固定序列，AM-GM 给出 `C ≤ (1 + mean(r))^252 − 1`；右侧对 `mean(r) > 0` 又大于 `A`，所以 AM-GM 本身不决定 gap 的符号。等号只在所有 `r_i` 相等（σ = 0）时成立，否则 `A` 与 `C` 是两个不同的函数。
- 一阶展开：`mean(log(1+r)) ≈ μ − (μ² + σ²)/2`，`C ≈ exp(252μ − 126(μ²+σ²)) − 1`，于是

```text
gap ≈ 126·σ² − 0.5·(252·μ)²          （μ、σ 为日频，结果换成小数再乘 100 得百分点）
```

  第一项是波动拖累（把 A 抬高于 C），第二项是均值的复利（把 C 抬高、缩小 gap）。符号翻转的临界点是 `σ ≈ √252 · μ ≈ 15.9 μ`：日波动低于日均值的约 16 倍时，算术年化反而低估复合年化。
- 对数正态下 `A` 与 `C` 有闭式解（见第 1 节），用来核对蒙特卡洛。

def secid(code):
    return ("1." if code.startswith("6") else "0.") + code


def fetch(code, tries=3):

                d, o, c = line.split(",")[:3]
                rows.append((d, float(o), float(c)))
            if any(o <= 0.0 or c <= 0.0 for _, o, c in rows):

            if len(rows) < 300:
                raise ValueError("too few rows")
            return rows
        except Exception as exc:
            last = exc
            time.sleep(1.0 + attempt)
    raise RuntimeError("%s: %s" % (code, last))


def arithmetic_pct(rets):
    return sum(rets) / len(rets) * YEAR * 100.0


def compound_pct(rets):
    prod = 1.0
    for r in rets:
        prod *= 1.0 + r
    return (prod ** (YEAR / len(rets)) - 1.0) * 100.0


def log_compound_pct(rets):
    total = sum(math.log1p(r) for r in rets)
    return (math.exp(total * YEAR / len(rets)) - 1.0) * 100.0


def stdev(rets):
    n = len(rets)
    mean = sum(rets) / n
    return math.sqrt(sum((r - mean) ** 2 for r in rets) / (n - 1))


def median(values):
    s = sorted(values)
    n = len(s)
    return 0.5 * (s[n // 2 - 1] + s[n // 2]) if n % 2 == 0 else s[n // 2]


def main():

          % (".".join(map(str, __import__("sys").version_info[:3])), YEAR, MC_M, MC_S, MC_PATHS, SEED))
    print()
    print("[1] deterministic counterexamples (252 daily returns)")

             ("B  +10% / -10%", [0.10, -0.10]),
             ("C  +2% / -1%", [0.02, -0.01]))
    for name, pair in cases:

        c = compound_pct(rets)

    mu = math.exp(MC_M + 0.5 * MC_S * MC_S) - 1.0
    c_med_analytic = (math.exp(YEAR * MC_M) - 1.0) * 100.0
    c_mean_analytic = ((1.0 + mu) ** YEAR - 1.0) * 100.0
    var = math.exp(2 * MC_M + MC_S * MC_S) * math.expm1(MC_S * MC_S)
    approx = (0.5 * YEAR * var - 0.5 * (YEAR * mu) ** 2) * 100.0
    print("  analytic arithmetic E[A]   = %+9.4f%%" % a_analytic)
    print("  analytic compound median   = %+9.4f%%   A - median(C) = %+9.4f pp"
          % (c_med_analytic, a_analytic - c_med_analytic))
    print("  analytic compound mean E[C]= %+9.4f%%   E[gap] = %+9.4f pp"
          % (c_mean_analytic, a_analytic - c_mean_analytic))
    print("  long-sample realized approx gap = 126*var - 0.5*(252*mu)^2 = %+.4f pp (mu=%.6f, var=%.6f)"
          % (approx, mu, var))
    rng = random.Random(SEED)
    a_samples, c_samples = [], []
    for _ in range(MC_PATHS):
        total_x = 0.0
        sum_r = 0.0
        for _ in range(YEAR):
            x = rng.gauss(MC_M, MC_S)
            total_x += x
            sum_r += math.expm1(x)
        a_samples.append(sum_r * 100.0)
        c_samples.append(math.expm1(total_x) * 100.0)
    a_mc = sum(a_samples) / len(a_samples)
    c_mc = sum(c_samples) / len(c_samples)

    gaps = [a - c for a, c in zip(a_samples, c_samples)]
    gap_med = median(gaps)
    gap_mean = sum(gaps) / len(gaps)

    print("  monte carlo arithmetic = %+9.4f%% (se %.4f)  compound mean = %+9.4f%% (se %.4f)  compound median = %+9.4f%%"

    print("  sha256(panel) = %s" % sha)

        mu = sum(rets) / len(rets)

        rows_out.append((code, len(rets), a, c, a - c, v, approx))
        print("  %-7s %5d  %+9.4f  %+9.4f  %+9.4f  %9.4f  %11.4f   %s"

    print()

    worst = 0.0
    for code, series in panel.items():

    return 0

| 等权组合 | 算术 +12.2560%、复合 +11.4291%、gap **+0.8269 pp**（年化波动 16.92%） |

三点读数：

1. **"等于"在数学上不成立，而且没有统一方向**。反例 A 里算术年化 +126%、复合 −11.8%（符号相反）；反例 C 里算术年化反而低估 115.7 pp。常见说法"算术平均总是高估"也不对：高估还是低估取决于波动与均值的相对大小，以及你比较的是单条实现路径（中位数）还是跨路径期望。
2. **机制**：`A = 252μ` 是线性年化，`C` 是对数收益的年化。对单条长样本路径，`C ≈ exp(252(μ − (μ²+σ²)/2)) − 1`，波动拖累让 gap 约为 `126σ²`；但 `gap` 里还有 `−0.5(252μ)²` 的复利项，均值越大、这一项越把 C 抬高，所以在低波动高均值时 gap 会翻负（反例 C）。跨路径期望则满足 `E[∏(1+r)] = (1+μ)^252`，`E[C]` 反而高于 `A`（本例 −1.2 pp）。
3. **实盘上 30/30 高估**，中位 4.08 pp；gap 的大小基本由 `126σ²` 决定（近似误差中位 0.25 pp）。等权组合因为分散化把波动降到 16.9%，gap 只有 0.83 pp。

## 5. 交叉验证

1. **确定性反例**：闭式 `(1.11×0.90)^126 − 1` 与逐日复利循环差 `1.07e-14 pp`；三段反例的 `A`、`C` 都可以手算复现（见第 3 节命令）。
2. **复合年化两种算法**：`∏(1+r_i)` 连乘后再开 `252/n` 次方，与 `(末价/首价)^(252/n) − 1` 在 30 只股票上最大差 `8.88e-14 pp`。
3. **蒙特卡洛 vs 解析**：`E[A]` 差 −0.2090 pp（2se = 0.6369）、`E[C]` 差 −0.1885 pp（2se = 0.7629）、`median(C)` 差 −0.2353 pp；`E[gap]` 差 0.0205 pp。
4. **首版实现修正记录**：最初把 10,000 条路径 `C` 的均值（+16.13%）与解析的 `median(C)`（+10.61%）相比，显示 5.5 pp 的"不一致"；这是均值/中位数定义混用，不是数据问题。修正为分别对照 `E[C]` 与 `median(C)` 后，差异都在蒙特卡洛误差内。主张、参数与判定规则（第 1–2 节）未改。
5. **实盘数据**：东财后复权（`fqt=2`）与 akshare 后复权的 600519 区间总收益比在第 4 轮已验证一致（2.177824）；本轮沿用同一接口与口径，30 只股票均有 2,078–2,159 个交易日。

## 6. 结论

**判定：`REFUTED`（模型级——算术年化与复合年化是两个不同的函数，反例即可推翻"恒等"）。**

| 判据 | 门槛 | 实测 | 是否成立 |
|---|---|---|---|
| R1 确定性反例 | `|gap| ≥ 10 pp` 或符号相反 | +137.8 pp 且符号相反（反例 A） | **是** |
| R2 对数正态 MC 与解析 | 差 ≤ 0.5 pp 且 `|E[gap]| ≥ 1 pp` | 差 0.02 pp，`E[gap]` = −1.20 pp | **是** |
| R3 30 只股票 | 100% 有 gap 且中位数 ≥ 2 pp | 30/30，中位 +4.08 pp | **是** |

- **"算术平均 × 252 = 可实现复合年化"不成立**：反例 A 的算术年化是 +126%，实际复合年化是 −11.84%；反例 C 则反向差 −115.7 pp。实盘 30 只股票全部高估，中位高估 4.08 pp。
- **连"总是高估"也不成立**：单条实现路径（中位数）通常是高估（MC median gap +2.48 pp，66% 的路径），但跨路径期望 `E[C]` 高于 `A`（−1.20 pp），因为 `E[∏(1+r)] = (1+μ)^252` 有 Jensen 项。方向取决于你比较的是"典型路径"还是"期望"。
- **一阶近似可用**：`gap ≈ 126σ² − 0.5(252μ)²`，实盘 30 只股票的近似误差中位数 0.25 pp；波动是主因，均值只在低波动时把 gap 拉回。
- 本仓库自己的工具没有这个错误：`dalio-all-weather/scripts/allocation.py` 的 `annual_metrics` 用几何年化（第 379–382 行），`framework-backtest/scripts/backtest.py` 用 `nav^(1/years)−1`（第 360 行）。本轮针对的是"把回测里的算术平均年化当成年化收益"的读法，不是工具 bug，因此不开 issue。

**本轮没有证明**：任何策略赚不赚钱、算术平均没有用。算术平均仍是单期期望收益的正确估计，也是夏普比率分子的标准口径；被推翻的只是"把它乘 252 当作长期可实现年化"这一步。

## 7. 边界与未证明的部分

- **数学结论是无条件的**（对任何非退化序列 `A ≠ C`），但**符号与量级依赖数据**：反例 A/C 展示两个方向；实盘 30 只股票只覆盖 2018–2026 的大市值 A 股，全部高估，不能外推到其他市场/时段。
- **年化约定**：252 个交易日、几何年化 `(∏)^(252/n) − 1`；换成 365 自然日或按周/月年化，数字会变，但 `A ≠ C` 不变。
- **实盘样本**：30 只 2026 年时点的大市值股，存在幸存者/选择偏差；gap 的**中位数**受样本选择影响，但"30/30 高估"这个方向在机制上由波动拖累决定，不是偶然。
- **成本**：不建模交易成本；本轮讨论的是收益统计量，不是可交易策略的净收益。
- **未证明**：夏普比率、波动率目标、杠杆产品的同类口径问题（这些是自然的后续主张，但不在本轮范围内）。
