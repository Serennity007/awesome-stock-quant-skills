# Round 2026-11-27（第 6 轮）· F-002 波动率风险溢价（方差互换代理）

- **状态**：`REFUTED`（方差互换代理口径）——第 1–3 节为计算前的登记，结果见第 4–6 节
- **主张**："当实际波动率低于隐含波动率时，卖出期权存在正期望（波动率风险溢价）。"（F-002 原文；此前因缺 IV/RV 数据标为 `BLOCKED`）
- **数据现状**：已接入 50ETF 期权 QVIX（30 日隐含波动率指数）与 510050 后复权日线（AKShare 1.18.94），覆盖 2015-02-09 至 2026-11-18，可以解除"缺数据"这一条。
- **可操作化定义**：
  - 用"卖出 21 个交易日的方差互换"作为"卖出波动率"的模型无关代理：收到 `IV_t²`、付出 `RV_{t,t+21}²`，`P&L = IV² − RV²`（vol-point²），另报 `IV − RV`（vol points）。
  - `IV` 取 QVIX 收盘（年化波动率，%）；`RV = sqrt(252/21 · Σ r²) × 100`，`r` 为 510050 后复权日收益。
  - "实际波动率低于隐含波动率"有两种读法：
    - **ex post**：用未来 21 日的 RV 判定——此时 `P&L > 0` 是代数恒等，不能检验，只作为恒等式展示；
    - **ex ante**：用 t 时点可观察的过去 21 日 RV 判定——这是唯一可检验的读法，本轮以此为主。
  - 因此本轮检验的是："在 t 时点观察到过去 21 日 RV 低于 IV 之后，下一期卖出方差互换是否仍有正期望"，而不是同义反复的 ex post 版本。
- **判定规则（计算前固定）**：
  - R1：ex ante 条件（`rv_trail < IV`）的均值 P&L > 0，块 bootstrap 95% 下界 > 0。
  - R2：ex ante 条件均值 > 无条件均值（配对 bootstrap 95% 下界 > 0），即该条件有增量信息。
  - R3：扣 0.5 vol-point 买卖价差后，R1 仍成立。
  - 结论映射：R1 且 R3 → `SUPPORTED`（方差互换代理口径）；R1 但不 R3 → `AMBIGUOUS`；R1 不成立 → `REFUTED`。R2 不成立时记"条件无增量信息"，不改变 R1 的判定。
- **代理口径的限制（先写清）**：期权链的实际到期损益没有测（仓库没有期权报价数据）；方差互换需要连续对冲、无跳跃、无资金成本，真实 P&L 会更差。本轮所有结论只对"卖出方差互换"这个代理成立，不外推到具体期权卖方策略。

## 2. 公式与代理说明

```text
r_t     = 510050_t / 510050_{t-1} − 1
RV_fwd  = sqrt(252/21 · Σ_{i=1..21} r_{t+i}²) × 100
RV_trail= sqrt(252/21 · Σ_{i=0..20} r_{t-i}²) × 100
P&L     = IV_t² − RV_fwd²              （vol-point²）
spread  = IV_t − RV_fwd                （vol points）
```

- 方差互换的到期损益在连续对冲、无跳跃、无套利的假设下等于 `IV² − RV²`；这是"卖出波动率"的模型无关近似，不是某一行权价期权的损益。
- 事件时间点 t 只使用 t 及以前的数据（IV_t、RV_trail），下一期 RV 只作为结果，不参与条件构造，避免前视。

#!/usr/bin/env python3
"""F-002 retry: variance-risk-premium proxy with 50ETF QVIX and 510050 ETF.

Sells one 21-trading-day variance swap per observation: receive IV_t^2, pay the
realised variance RV_{t,t+21}^2. This is the model-free replication of a short
volatility position, NOT an option seller's realised P&L (no option chain is used).
Design and decision rules are frozen in
falsification/rounds/2026-11-27-round6.md before this script is run.
"""
import numpy as np
import pandas as pd
import akshare as ak

START, END = "20150101", "20261231"
H = 21              # trading days per observation (1 month)
TRADING = 252
COSTS = (0.0, 0.5, 1.0)   # variance-swap half spread, vol points
SEED = 20261127
REPS = 2000
BLOCK = 21


def fetch():
    iv = ak.index_option_50etf_qvix()
    iv["date"] = pd.to_datetime(iv["date"])
    iv = iv.dropna(subset=["close"])[["date", "close"]].rename(columns={"close": "iv"})
    etf = ak.fund_etf_hist_em(symbol="510050", period="daily",
                              start_date=START, end_date=END, adjust="qfq")
    etf = etf.rename(columns={"日期": "date", "收盘": "etf"})
    etf["date"] = pd.to_datetime(etf["date"])
    df = pd.merge(iv, etf[["date", "etf"]], on="date", how="inner")
    return df.sort_values("date").reset_index(drop=True)


def realized_vol(close, h, forward):
    r = close.pct_change()
    sq = r * r
    roll = sq.rolling(h).sum()
    if forward:
        roll = roll.shift(-h)
    return np.sqrt(TRADING / h * roll) * 100.0


def block_boot(values, stat, block=BLOCK, reps=REPS, seed=SEED):
    x = np.asarray(values, dtype=float)
    n = len(x)
    nb = max(1, n // block)
    rng = np.random.default_rng(seed)
    out = np.empty(reps)
    offsets = np.arange(block)
    for i in range(reps):
        starts = rng.integers(0, n, nb)
        idx = ((starts[:, None] + offsets[None, :]) % n).reshape(-1)
        out[i] = stat(x[idx])
    return out


def main():
    df = fetch()
    df["rv_fwd"] = realized_vol(df["etf"], H, True)
    df["rv_trail"] = realized_vol(df["etf"], H, False)
    df["pl"] = df["iv"] ** 2 - df["rv_fwd"] ** 2
    df["spread"] = df["iv"] - df["rv_fwd"]
    df["cond"] = df["rv_trail"] < df["iv"]
    valid = df.dropna(subset=["rv_fwd", "rv_trail"]).reset_index(drop=True)
    print("Python %s | 50ETF QVIX + 510050 qfq | horizon=%d trading days | obs=%d"
          % (".".join(map(str, __import__("sys").version_info[:3])), H, len(valid)))
    print("  sample %s..%s   mean_iv=%.2f   mean_rv_fwd=%.2f   share(iv>rv_trail)=%.3f"
          % (valid["date"].iloc[0].date(), valid["date"].iloc[-1].date(),
             valid["iv"].mean(), valid["rv_fwd"].mean(), valid["cond"].mean()))
    print("  mean(iv^2)=%.1f   mean(rv_fwd^2)=%.1f   median(iv^2-rv_fwd^2)=%.1f"
          % ((valid["iv"] ** 2).mean(), (valid["rv_fwd"] ** 2).mean(),
             np.median(valid["iv"] ** 2 - valid["rv_fwd"] ** 2)))

    def describe(mask, label):
        x = valid.loc[mask, "pl"].values
        s = valid.loc[mask, "spread"].values
        print("  %-22s n=%4d  mean_pl=%+9.3f  median_pl=%+9.3f  mean_spread=%+6.2f  share_pl>0=%.3f"
              % (label, len(x), x.mean(), np.median(x), s.mean(), (x > 0).mean()))
        return x, s

    print()
    print("[1] unconditional")
    x_all, s_all = describe(np.ones(len(valid), dtype=bool), "all observations")
    print()
    print("[2] ex-ante condition: trailing RV(21) < IV at t")
    x_c, s_c = describe(valid["cond"].values, "cond: rv_trail < iv")
    x_nc, _ = describe(~valid["cond"].values, "not cond")
    print()
    print("[3] ex-post condition (tautology check): future RV < IV")
    ex_post = valid["rv_fwd"] < valid["iv"]
    describe(ex_post.values, "cond: rv_fwd < iv")
    print("  note: when rv_fwd < iv, pl = iv^2 - rv_fwd^2 > 0 by algebra (zero cost)")

    print()
    print("[4] costs: subtract c from IV before squaring")
    for c in COSTS:
        pl_c = (valid["iv"] - c) ** 2 - valid["rv_fwd"] ** 2
        mask = valid["cond"].values
        print("  c=%.1f vol pts  all: mean=%+9.3f  share>0=%.3f | cond: mean=%+9.3f  share>0=%.3f"
              % (c, pl_c.mean(), (pl_c > 0).mean(), pl_c[mask].mean(), (pl_c[mask] > 0).mean()))

    print()
    print("[4b] per-year mean P&L (unconditional, zero cost)")
    valid["year"] = valid["date"].dt.year
    for y, g in valid.groupby("year"):
        print("  %d  n=%3d  mean=%+9.2f  median=%+9.2f  share>0=%.3f  mean_iv=%.1f  mean_rv=%.1f"
              % (y, len(g), g["pl"].mean(), g["pl"].median(), (g["pl"] > 0).mean(),
                 g["iv"].mean(), g["rv_fwd"].mean()))

    print()
    print("[5] bootstrap (block=%d, reps=%d, seed=%d)" % (BLOCK, REPS, SEED))
    boot_all = block_boot(x_all, np.mean)
    boot_cond = block_boot(x_c, np.mean)
    print("  mean_pl all   = %+9.3f  95%% CI [%+9.3f, %+9.3f]  p(mean<=0)=%.4f"
          % (x_all.mean(), np.percentile(boot_all, 2.5), np.percentile(boot_all, 97.5),
             (boot_all <= 0).mean()))
    print("  mean_pl cond  = %+9.3f  95%% CI [%+9.3f, %+9.3f]  p(mean<=0)=%.4f"
          % (x_c.mean(), np.percentile(boot_cond, 2.5), np.percentile(boot_cond, 97.5),
             (boot_cond <= 0).mean()))
    # paired bootstrap of cond - all (same resampled dates, same condition mask)
    rng = np.random.default_rng(SEED)
    n = len(valid)
    nb = max(1, n // BLOCK)
    offsets = np.arange(BLOCK)
    mask = valid["cond"].values
    pl = valid["pl"].values
    diffs = np.empty(REPS)
    for i in range(REPS):
        starts = rng.integers(0, n, nb)
        idx = ((starts[:, None] + offsets[None, :]) % n).reshape(-1)
        vals = pl[idx]
        m = mask[idx]
        diffs[i] = vals[m].mean() - vals.mean() if m.any() else np.nan
    diffs = diffs[~np.isnan(diffs)]
    print("  diff(cond - all) = %+9.3f  95%% CI [%+9.3f, %+9.3f]  p(diff<=0)=%.4f"
          % (x_c.mean() - x_all.mean(), np.percentile(diffs, 2.5), np.percentile(diffs, 97.5),
             (diffs <= 0).mean()))

    print()
    print("[6] cross-checks")
    r = valid["etf"].pct_change().values
    manual = np.full(len(r), np.nan)
    for i in range(len(r) - H):
        window = r[i + 1:i + 1 + H]
        if not np.isnan(window).any():
            manual[i] = np.sqrt(TRADING / H * np.sum(window ** 2)) * 100.0
    diff = manual - valid["rv_fwd"].values
    diff = diff[~np.isnan(diff)]
    print("  RV pandas rolling vs manual loop: max_abs_diff = %.3e (n=%d)" % (np.max(np.abs(diff)), len(diff)))
    t = x_all.mean() / (x_all.std(ddof=1) / np.sqrt(len(x_all)))
    print("  naive t-stat (iid, overlapping) = %.2f (not used for judgement)" % t)
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

## 5. 交叉验证

1. **RV 两种实现**：pandas `rolling(21).sum().shift(-21)` 与逐段手写循环在 2,785 个窗口上最大差 **1.42e-14**。
2. **条件/非条件的一致性**：条件组 + 非条件组按样本数加权应等于全样本均值；`(1787×−11.668 + 1019×−241.968)/2806 = −95.30`，与 [1] 的 −95.301 一致（差 < 0.01）。
3. **配对 bootstrap**：条件组与全样本用同一组日期重采样，差值 +83.634，95% CI [+10.772, +173.204]，与两组单独重采样的方向一致。
4. **朴素 t 统计量** −6.90 只作对照，因 21 日窗口重叠会夸大显著性，判定不用它。
5. **数据口径**：QVIX 是 30 日恒定到期隐含波动率指数，RV 用 21 日窗口，两者期限不完全匹配；这是代理口径的已知误差，不修正。

## 6. 结论

**判定：`REFUTED`（方差互换代理口径——按预登记 R1，ex ante 条件均值未为正）。**

| 判据 | 门槛 | 实测 | 是否成立 |
|---|---|---|---|
| R1 ex ante 条件均值 > 0 | 95% 下界 > 0 | −11.668，CI [−85.679, +55.455] | **否** |
| R2 条件均值 > 无条件均值 | 95% 下界 > 0 | +83.634，CI [+10.772, +173.204] | **是** |
| R3 扣 0.5 vol-point 后 R1 仍成立 | 均值 > 0 | −30.864 | **否** |

- **"观察到 RV < IV 之后卖出波动率仍有正期望"在本样本不成立**：条件均值 −11.7，区间跨 0；成本后 −30.9。条件筛掉了最差的样本（非条件组 −242），但没有把期望变成正数。
- **ex post 版本无法被检验**：它是代数恒等（100% 为正），不构成证据；主张原文若按字面读，等于把结论写进了条件里。
- **"正期望" ≠ "高胜率"**：条件组 72.1% 的窗口为正、中位 +84.2，但 2015 年的尾部把均值打到 −1231 那一档，全样本均值 −95.3。短波动率是"多数小赢、少数大亏"的结构，和 F-001 的结论一致。
