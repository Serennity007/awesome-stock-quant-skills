# Round 2026-11-27 · F-001 高胜率卖方 ≠ 正期望

- **状态**：`REFUTED`（模型级——在公平 Black-76 定价下不成立）
- **主张**："卖出深度虚值期权，因为胜率高，所以长期稳定盈利。"
- **可操作化定义**：以单一期货合约为标的的欧式看涨期权；卖方收取公平价，到期按内在价值结算；"长期盈利"指到期损益的期望（贴现后）为正。
- **判定规则**：若在公平定价下，不同虚值程度的卖方期望损益都相同（且不随胜率升高而改善），则该主张不成立。

## 1. 输入与参数（先登记，后计算）

| 参数 | 值 |
|---|---|
| 期货价格 F | 100 |
| 期限 | 90 个自然日（T = 90/365） |
| 无风险利率 r | 3% |
| 波动率 σ | 25% |
| 行权价 K | 90 / 100 / 105 / 110 / 120 / 130 |
| 单边成本（简化） | 0.10 个价格点/手 |
| 定价 | Black-76 欧式期权；风险中性对数正态 |

## 2. 方法与公式

公平看涨价 `P = e^{-rT} · [F·N(d1) − K·N(d2)]`，其中 `d1 = (ln(F/K) + σ²T/2)/(σ√T)`，`d2 = d1 − σ√T`。

在风险中性测度下，卖方到期损益的贴现期望为：

```
E[P&L] = P − e^{-rT} · E[(S_T − K)^+] = 0
```

而"胜率"（到期时期货低于行权价、卖方收下全部权利金的概率）为 `N(−d2)`。两者是不同量：胜率随 K 升高而升高，但期望与 K 无关。

## 3. 复现命令

```bash
python - <<'PY'
import math
def N(x): return 0.5*(1+math.erf(x/math.sqrt(2)))
F, T, r, s, cost = 100.0, 90/365, 0.03, 0.25, 0.10
for K in (90.0, 100.0, 105.0, 110.0, 120.0, 130.0):
    d1 = (math.log(F/K) + 0.5*s*s*T)/(s*math.sqrt(T)); d2 = d1 - s*math.sqrt(T)
    prem = math.exp(-r*T)*(F*N(d1) - K*N(d2))
    win = N(-d2)
    print(f"K={K:6.1f} premium={prem:.6f} win={win*100:6.2f}% EV0=0 EVcost={-cost:.2f}")
PY
```

## 5. 结论

- 胜率从 **21.6%** 升到 **98.5%** 时，公平定价下的贴现期望损益始终为 **0**（含 0.10 点成本后始终为 **−0.10**）。
- 因此"胜率高"不能推出"长期盈利"；该主张在公平定价模型下**被推翻**。高胜率只是把盈亏结构变得"多数小赢、少数大亏"，不改变期望。

## 6. 边界与未证明的部分

- 这是**模型级**证伪：假设市场按 Black-76 公平定价。真实市场存在波动率风险溢价、报价摩擦与分歧，可能让卖方期望偏离 0——那属于另一个主张（F-002，`OPEN`），需要真实 IV/RV 数据检验。
- 成本只按 0.10 点/手简化建模，未含保证金、资金占用、跳空与流动性。
- 未使用任何真实行情数据；本记录不构成交易建议。
